## 原则

- 每个实验必须保存配置快照、代码 commit、随机种子、数据版本与运行环境。
- 模型规模、粒子数、损失权重与约束强度由开发集选择；不得在测试集上调参。
- 与基线比较时记录 prompt tokens、总推理 tokens、时延、算力与成本。
- P0 与 P1 使用不同的数据根与评价入口，禁止混用。
- 任何“最佳配置”必须由真实运行产生，不得写入预期数字。
