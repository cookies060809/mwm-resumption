## 3. 技术方案 PDF 检查

- [ ] 使用官方模板与参考大纲（项目概述、算法设计、实验验证与应用、总结与展望、附录）
- [ ] 问题定义清楚：外部观察者、部分可观测、跨中断、T1/T2/T3
- [ ] 算法设计包含原理、架构图、核心公式与推导
- [ ] 训练数据来源、预处理、规模、训练设置与优化策略
- [ ] 实验环境（硬件、软件、依赖版本）
- [ ] 基线选择与公平比较（相同输入/基座/预算）
- [ ] 真实实验数据与对比分析；无编造数字
- [ ] P0 与 P1 结果分开；P0 不写成真实人类预测
- [ ] 消融、校准、效率、失败案例
- [ ] 应用场景与应用价值；未落地则不写“已应用”
- [ ] 附录含核心代码片段、数据说明、参考文献
- [ ] 文件 ≤10MB，字体嵌入，页码完整
- [ ] 全文无学校名称、Logo、指导教师信息

## 4. 演示视频检查

- [ ] MP4 / H.264，1080p，3–5 分钟，≤300MB
- [ ] 开头 30 秒讲清问题与对象
- [ ] 展示核心方法，而不是只念 PPT
- [ ] 展示一条真实运行/原型演示；如未实现须明确说明
- [ ] 结果图与表格来自真实运行
- [ ] 字幕、旁白、画面无学校/Logo/指导教师
- [ ] 结尾给出作品名与一句话价值

## 5. 答辩 PPT 检查

- [ ] 按评分项组织：创新性、技术难度、实验验证、完整性、应用价值、总结展望
- [ ] 每页一个核心信息
- [ ] 公式可读，图表清晰
- [ ] 所有数字可追溯到结果目录
- [ ] 诚实报告局限与失败案例
- [ ] 导出 PDF 并检查兼容性
- [ ] 无学校/Logo/指导教师

## 6. 代码与复现

- [ ] 代码包/仓库包含 README、依赖、运行命令
- [ ] 环境版本、硬件、随机种子、配置快照
- [ ] 数据版本/哈希与划分说明
- [ ] 核心结果可由脚本复现
- [ ] 不包含 P1 原始数据、个人信息、密钥
- [ ] 第三方代码/数据有许可与引用说明
- [ ] 仓库链接对评委可访问（如私有，提交时开放或提供代码包）
