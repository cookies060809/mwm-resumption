# 工程脚本

## `validate_data.py`

校验 P0 数据与 P1 模板：

- JSON Schema 结构、枚举与必填字段；
- 事件 ID 唯一、`cutoff_event_id` 存在；
- 状态证据 ID 属于已观察事件；
- 任务图步骤引用合法；
- `Q`、P0 预期步骤、P1 恢复步骤指向合法步骤；
- 观察事件时间不晚于截断事件（可解析时）；
- 成对样例双向引用、同族同 pair、变体不同、split 一致。

用法：

```bash
python scripts/validate_data.py
```

退出码：`0` 全部通过；`1` 存在错误。

## 边界

该校验器只检查结构与基本一致性，**不替代**：

- 隐私/许可审查；
- 双人标注与仲裁；
- 未来信息泄漏的人工审计；
- 统计口径与结果复现检查。

新增校验规则时，同时更新 `schema/README.md` 与本文件，并添加测试。
