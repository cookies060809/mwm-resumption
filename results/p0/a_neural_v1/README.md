## 协议与适用范围

固定T1阈值0.5、ECE10等宽箱；T2仅恢复为true且首步属于原目标、未客观完成的样本；T3仅非UNKNOWN且cutoff证据有效，逐因子计数。Q按图内位置池化。T2缺失计错；无双类别的AUROC为null。
A1故意取消接触/理解门控；A2独立BCQ后验；A3仅保留最近5事件的人物记忆但重放所有世界事实；A4移除事件语义软对齐及信息等价JS；A5去步骤训练损失但仍评测；A6固定接触/理解/采信等结构转移门控，保留公共可学习世界先验及行为头。

## 结果解释与失败边界

主批144/48/48条train/dev/test中，test的T1有效42条（6条indeterminate屏蔽）、T2有效18条；T3的B为45条，其他因子各48条。全部140次均完成40轮且dev选择第40轮；这不证明40轮为最优训练时长。所有重载误差为0；另从头重复A0 seed0，选中轮次与保存模型的全部张量逐位一致。

A3的T1优于A0而T3下降；A4与A0接近；A0与A1的T3相同。因此不能声称完整模型全面最优或每个机制普遍有效。T2仅18个有效脚本样本，多数变体饱和；20种子不会增加独立人物或场景样本。

主批A0的C/Q各有3条零支持：P02-D2-B、P02-D4-B、P02-S1-B先出现goal_abandoned，后出现step_started，当前核重新激活承诺与进度，而cutoff标签保留ABANDONED/NOT_APPLICABLE。需要与B仲裁时序及标签口径；不能通过门控概率拟合解决结构零支持，也未修改B标注。

v0.3的14条仅作冻结模型补充诊断：A0 T1 F1为0.5295±0.0222，T2 top1为1.0000（有效3条）。C有10条零支持：9条中断事件的semantic.kind=none未触发当前结构核的暂停转移；另1条ACTIVE标签与commitment_expressed固定进入SUSPENDED及后续自由文本动作未解析有关。A亦有2条零支持。这些是A覆盖假设与B事件编码的边界，不能归因于训练不足或宣称已完整处理不确定事件。下一轮A应在重新冻结协议后修订转移覆盖；本轮查看test后未修改模型、掩码或预算。
