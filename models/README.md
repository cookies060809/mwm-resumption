# 模型目录

> A 分支现已接入通用精确/SMC数值内核及实际P0输入适配，尚无已训练认知转移或端到端预测模型。公共M1接口仍待团队评审。详见 [A接口](../docs/internal/a/A_INTERFACES.md) 和 [P0检查](../docs/internal/a/A_P0_CHECK_REPORT.md)。

## 组成

| 目录 | 作用 | Owner |
|---|---|---|
| `ec_jmf/` | 联合心智状态滤波核心：状态转移、信息可达性门控、后验更新、恢复预测头 | A |
| `ecr_mwm/` | 端到端包装、T1/T2/T3 输出、与 MENTIS 的适配 | A（C 负责集成验证） |

## 统一输入输出

输入：

- 截至 `t` 的事件流 `O_{1:t}`；
- 任务图 `G=(K,D)`；
- 事件交付/接触证据 `D_t`；
- 截至 `t` 的人物可观察行动 `O_t^{act}`；
- 预测窗口 `H`。

输出：

- 联合后验 `b_t(Z_t)` 或粒子/边际分布；
- T1：`P(resume within H | X_t)`；
- T2：`P(Q^*=k | resume, X_t)`；
- T3：`V/F/A/B/C/Q` 的标签分布与证据引用；
- 证据路径、预测不确定性、成本记录。

## 禁止事项

1. 不得把观察者看到的客观事实直接复制为人物信念；必须经过接触/理解证据门控。
2. 不得使用 `t` 之后的行动或标签更新 `b_t`。
3. 不得把推断时 SMC 说成端到端可微训练；训练与推断的边界必须记录。
4. 不得把 P0 脚本结果包装成真实人类预测能力。
5. 不得在未做基线与消融前宣称性能优势。

## 实现顺序

按研究方案第 5.9 节：

- **S0**：结构化事件 + 精确滤波/规则，验证管道与未来泄漏；
- **S1**：用有依据的状态转移标签训练 `T^AU/T^B/T^C/T^Q`；
- **S2**：联合行为训练 T1/T2，状态缺失因子掩码；
- **S3**：加入信息等价反事实约束与消融；
- **S4**：启用 SMC，复核精确推断一致性并在独立集校准。
