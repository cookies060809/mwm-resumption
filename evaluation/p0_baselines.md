# P0 v0.2 本地基线诊断

本轮使用 main 提供的冻结 P0 v0.2：120 个 A/B 家族、240 条脚本记录、1831 条事件，train/dev/test 分别为 144/48/48 条。B 已标记 reviewed；A/C 人工盲审与仲裁尚未完成。这些结果用于诊断接口和机制，不代表真实人类恢复预测或 EC-JMF 主结果。

## 可复现入口

```bash
python -m pip install -r requirements-dev.txt
python scripts/run_p0_evaluation.py
python scripts/check_p0_reproducibility.py
python scripts/export_evaluation_snapshot.py
```

完整逐样例结果、输入与代码哈希、状态、错误、成本、机制诊断和离线展示生成在 `results/p0_v02/`，默认不提交。可共享的小型技术快照为 [p0_v02_results.json](p0_v02_results.json)，不含逐样例输入或答案。CI 自动运行正式 P0 与预测复现；复现比较六种方法 × 三种子 × 48 条测试记录的 864 条预测，忽略运行耗时。

## 输入映射与隔离

`mwm_eval/p0.py` 使用版本 `c-p0-v02-adapter/1.0.0`，不改 B 的原始数据、schema、划分或导出文件。修正三处语义对接：统一 `target_person="person"` 以匹配事件 actor；由可见通知内容类型映射通知语义；不将“被打断的原目标 ID”误用为“插入任务 ID”。不补造嵌套任务快照。映射仍需 A/B 评审。

输入与 gold 分文件，预测器只接收 cutoff 前的 observation，不接收故事 ID、机制名称、划分、未来行为或答案。数据校验要求故事、人物、任务骨架在任意两个划分间均无交集。B6/B7 只在训练集拟合；本轮不根据测试结果调整规则或阈值。dev 保留，未用作校准集。

## 结果口径

每种方法、每个种子均完成 48 条测试预测，无执行失败。T1 有 42 条可评分记录，另 6 条 future_leak 无可识别点真值；T2 有 18 条可识别原目标恢复步骤。下表为三种子均值，准确率的分母按对应任务计算。

| 方法 | 实现 | T1 准确率 | 恢复类 F1 | T2 步骤准确率 |
|---|---|---:|---:|---:|
| B0 | 目标/进度规则 | 0.4286 | 0.5556 | 0.8333 |
| B1 | 五事件短窗 | 0.7143 | 0.6667 | 0.6667 |
| B4 | 目标日志记忆 | 0.7857 | 0.7692 | 0.8333 |
| B5 | 可接触证据规则 | 0.7143 | 0.7143 | 0.8333 |
| B6 | 激活特征逻辑回归 | 0.6429 | 0.2857 | 0.1667 |
| B7 | 普通 HMM | 0.5714 | 0.0000 | 0.0000 |

B1/B6/B7 是有明确局限的本地参考实现，不声称严格复现 SET-PR、心理学原模型或 SIPS。T2 读取实际 `resume_step`，模型未给出步骤计错；分母按 gold 恢复确定，不只在模型预测恢复时评分。T3 仅对有截止证据支持的状态标注评分，并同时报告输出覆盖率。

## 机制检查与解释限制

八类机制逐对检查，`match_gold` 要求 A/B 两位均正确；future_leak 单独检查硬决策、恢复概率、状态分布和条件步骤分布是否一致。未输出分布时记为缺失，不假装通过。P04 他人完成后的重复动作不是任务恢复；P06-B 嵌套任务动作不是原任务步骤；P07 不确定决策只做不变性诊断。

本批没有独立 calibration split，概率保持原样，不能称为已校准概率。HMM 在本轮全部给出不恢复决策；很低的 ECE 可能来自近似常数概率接近总体恢复率，不能据此声称具有辨别能力。

测试集只有三个任务骨架。配对 Bootstrap 按任务骨架抽样而不是把 24 个家族当作完全独立样本；区间只作探索性诊断。三次种子不是三倍人物数，脚本准确率不支持真实人类泛化或论文显著性结论。当前无完整 A 模型、真实 LLM 或 MENTIS 运行结果。
