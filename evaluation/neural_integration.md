# A 神经模型的 C 侧接入与独立运行

## 扫描与版本

本轮扫描了全部五个远程分支。扫描时 main 与 `feat/a-p0-v02-ec-jmf` 均指向 `28525fb03a29ee27c0c85a1d0911f4bbffc0cf57`，其中新增神经实现与 A 自己的结果；旧 `feat/a-ec-jmf-p0-adapter` 为 `075fa99`，qiqi 为 `f74b9ce`，扫描前 Bill 为 `7700ef7`。新源码已合入 Bill，不修改 main。

模型包含 world/person 两个独立 GRU 编码器、可训练的状态转移门控、恢复行为头及步骤头。输入是类型化事件与已给定的接触/理解证据，不是从自由文本学习心理状态；网络结构之外仍有有限状态拓扑与规则约束。A 的神经模型、适配器、原配置及 B 原始数据没有被 C 修改。

## 原实验独立复现

先在 A 原来的 v0.2（144/48/48）上从头训练 A0 seed0，40 轮、开发集选模。训练参数逐张量与 A 上传的固定 checkpoint 完全一致；两个编码器均有实际参数更新。该代表模型在 C 协议下 T1 为 33/42（78.57%），与本批 B4 相同。不能把单个种子的分数当成 20 种子均值。匿名指纹和指标见 [neural_p0_v02_reproduction.json](neural_p0_v02_reproduction.json)。

## 完整 v0.3 运行协议

正式入口为 `data/p0/v0.3/p0_samples.json`：254 条，train/dev/test=150/52/52，calibration=0；来源 SHA256 为 `93ca37e93442495039950c0f8c4c618fee4b8b178cfc52c3269b33cb9f0f7739`。只在 train 反向传播、按 dev 相同损失选择 checkpoint；T1 阈值固定 0.5，不在 test 上选模型或阈值。

完整 A0 和 A1–A6 均使用 20 个固定种子、40 轮、相同 AdamW 设置，总计 140 个训练配置。所有 train/dev 选择冻结后，才进行统一测试；六种本地基线在同一 train/test、同一截止证据上重跑。A0 在公共结果中叫 `B10_NEURAL`，消融叫 `NEURAL_A1` 等，不覆盖旧数值参考 `B10` 的历史成绩。

模型测试批次仅传入 input，不包含 target、样本 ID、机制或家族字段。每个模型实际序列化并 weights-only 重载，核对重载预测；另固定重训 A0 seed0 检查逐位一致。逐条预测、真实证据轨迹和一份预先指定的代表 checkpoint 保留本地，不把 20 个种子当成新增人物或样本。

本轮未使用多源辅助包 JSONL；它仍需单独做事件语义适配及辅助任务头。完整 v0.3 已含 14 条补充各一次，不再把旧补充作为独立泛化集重复评分。所有结果仍是脚本 P0；人工独立盲审、既有标签仲裁、真实 P1、校准与 MENTIS 对照没有因神经训练而自动完成。

## 两套指标的定义

- T1：A 与 C 的准确率、恢复类 F1、Brier 逐种子核对一致。
- T2：A 内部按条件步骤分布 argmax 评分；C 对实际输出的步骤评分，模型判为不恢复时不输出步骤，因此漏判恢复会计步骤错误。两者同时保留，不强行改成同一个分数。例如原 v0.2 A0 seed0 的条件步骤正确率为 18/18，C 实际步骤正确率为 15/18。
- T3：A 内部只平均 gold 中支持的类别，并把 Q 按图内位置池化；C 按公共协议统计 gold/预测类别及原步骤名。保留逐因子分母和两套定义，不将其 macro-F1 混报。

新增四项神经接入测试覆盖真实梯度训练/重载、监督与身份隔离、P07 未来泄漏成对一致性，以及条件步骤与实际输出的区别；本地完整 168 项测试通过。CI 单独安装 CPU PyTorch 跑神经边界测试，不在 CI 执行 140 次完整训练。

## 重跑与匿名导出

依赖见 `requirements-dev.txt` 和 `requirements-neural.txt`，本轮 CPU PyTorch `2.11.0+cpu`，单线程。

```bash
python scripts/run_neural_p0_evaluation.py
python scripts/export_neural_evaluation.py --results-dir results/c_neural_v03 --output evaluation/neural_p0_v03_results.json
```

匿名导出前核对源码、数据、代表 checkpoint 和全部逐条预测的哈希；不上传逐条预测和本地依赖。实际分数以 [neural_p0_v03_results.json](neural_p0_v03_results.json) 为准。

## 完整 v0.3 实测结果

140 个神经训练配置、120 个本地基线运行全部完成，13,520 条测试预测无失败。T1 每次有效分母 46（另 6 条 UNKNOWN 不计），T2 每次有效分母 20。下表是同一固定测试集上 20 种子的均值；± 是训练随机性的样本标准差，不是人群置信区间。

| 方法 | T1 准确率 | 恢复类 F1 | C 实际输出步骤准确率 |
|---|---:|---:|---:|
| A0 完整神经模型 | 82.50% ± 3.19% | 0.8156 ± 0.0404 | 89.75% ± 7.34% |
| A1 | 78.26% ± 0.00% | 0.7619 ± 0.0000 | 80.00% ± 0.00% |
| A2 | 78.26% ± 0.00% | 0.7727 ± 0.0000 | 85.00% ± 0.00% |
| A3 | 83.48% ± 2.68% | 0.8279 ± 0.0339 | 92.00% ± 6.16% |
| A4 | 82.50% ± 3.19% | 0.8156 ± 0.0404 | 89.75% ± 7.34% |
| A5 | 82.50% ± 3.19% | 0.8156 ± 0.0404 | 55.50% ± 45.33% |
| A6 | 81.20% ± 3.33% | 0.7990 ± 0.0421 | 86.75% ± 7.66% |
| B4 规则对照 | 78.26% ± 0.00% | 0.7727 ± 0.0000 | 85.00% ± 0.00% |

完整模型平均准确率高于 B4 4.24 个百分点，但 seed0 二者均为 36/46；seed0 按 task_family 的配对 bootstrap 差值区间约为 [-8.82%, 9.09%]，仅 5 个任务家族。它不是 20 种子均值差异的置信区间，不能据此宣布统计显著。A3 均值高于完整模型，A4 与完整模型三项汇总相同，A5 步骤预测波动较大；这些是后续机制排查线索，尚不能宣称所有模块都带来增益，也没有据此重新选模型。

所有模型重载预测完全一致；预先指定的 A0 seed0 独立重训参数一致。168 项测试通过，导出验证全部源码、数据、checkpoint 和预测哈希一致。旧数值参考 B10 的 56.5% 与本轮神经模型 B10_NEURAL 的 82.5% 是不同实现，不覆盖历史记录。这里使用完整 v0.3 自带的 train/dev/test；A 原实验配置中的“v0.3 仅补充诊断”描述的是其原 v0.2 实验，本轮完整发布版训练协议以本节及实际 data.path 为准。
