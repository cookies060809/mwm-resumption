## 写作与核查原则

1. 文档中的“计划”“目标”“拟实现”必须与“已完成”“已验证”明确分开。
2. 引用论文时优先给出原文链接；二手解读不得写成全文精读结论。
3. 任何性能数字必须能追溯到实验配置、代码 commit 与结果目录。
4. P0 脚本结果与 P1 真实行为结果不得混写。
5. 标注规则变更必须更新手册版本，并在 `schema_version` 或迁移说明中体现。
