# A 正式算法选择与风险计划

日期：2026-10-21。本文定义可复用的算法选择、信息边界和验收要求；当前实现包含通用推断核、v0.1/v0.2适配、有限结构化联合更新，以及PyTorch可微精确滤波训练、dev选模和模型重载。已完成A0–A6各20种子的脚本P0诊断并保存预指定A0 seed0模型；正式结果与失败边界见 `results/p0/a_neural_v1/README.md`。尚无P1真实行为实验。数据/schema由B维护，评测与MENTIS集成由C维护；公共M1接口仍待团队确认。

## 选择

小状态空间使用精确联合滤波作有限状态数值参考；大状态使用相同转移/观测核的bootstrap SMC。两者已迁通用实现，不等于已完成可学习EC-JMF。均值场会削弱B/C/Q相关性，beam截断会丢尾部质量，暂作未来近似消融；Rao–Blackwell化需确定可解析条件块后再引入。LLM解析、BDI、HMM/SMC公平基线按团队研究计划比较，不能预设优势。

六维标签不满足一般Markov充分性，内部状态需增广世界/人物完成集合、目标记忆和必要中断栈，并隔离世界/人物编码。以下门槛用于工程验收，不代表模型有效性或最优性能已获证明。

## 信息与状态

世界W与心智M分离。AU门控只能使用本事件交付证据和人物可获得内容，禁止共享包含世界事实的embedding/cache。A/U逐事件重判，不沿用上次“已读”。C/Q输入、人物任务图和完成集合也只来自人物信息；客观图不自动等于人物图。后台取消可以改变世界，不能直接把人物信念改成无效。

### 长期约束：世界事件、接触、理解与主观信念

后续设计和测试必须分别表示以下四个层次，不能以一个字段替代其余层次：

|层次|含义与更新依据|
|---|---|
|客观世界事件|记录实际发生的取消、完成、资源变化等事实及其证据；世界状态可据此更新，但不推出人物已知该事实。|
|人物接触证据|单独记录信息是否进入人物可获得的通道、是否有接收证据，以及证据是否不足。沿用A/D的接触证据含义，不把接触当作知识或理解。|
|人物理解情况|区分正确理解、误解与理解情况不明；U是设计中的内部辅助变量，不因已读或ACCESSED就赋为正确理解，也不把缺少理解证据自动当作误解。|
|人物主观信念|B依据人物实际可获得的信息、其理解/采信情况和既往信念更新；允许错误信念、暂时未决及证据不足，不直接复制客观状态。|

后台事实单独存在，不足以作为人物已经知道该事实的依据。人物接触信息，也不等于已理解、采信或记住内容。人物可获得的间接线索仍可提供更新依据；“没有收到某条通知”不意味着所有信念必须永远不变。`UNRESOLVED`用于有证据表明人物暂时无法判断的情况；`UNKNOWN`用于观察者缺乏足够证据，二者不混用。本段是长期建模约束，不新增正式schema字段，也不宣称理解模型已经实现。

**例一：人物没收到取消通知。** 后台已取消任务，但人物既未收到通知，也没有获得其他能察觉取消的线索。世界侧可以记录取消；人物侧不能仅凭后台记录就被确定为“已知取消”，也不能据此自动判定其已放弃。应保留与既有信息相容的信念或不确定性，而非强行填入正确答案。

**例二：人物收到但误解通知。** 人物确已阅读取消通知，却明确将其理解为“暂缓，等待进一步通知”。接触证据可以是ACCESSED，理解仍是误解；其信念可以继续认为目标有效或处于未决状态，不能强制改为“相信目标已取消”。具体判断须由其陈述、行动和可获得证据支持，不将该例写成所有人的固定反应规则。

今后的设计复核与测试应分别控制“世界是否变化”“人物是否接触”“人物如何理解”，检查以上两例是否保留客观/主观分离；不得只验证接触字段存在，便声称已验证理解或信念更新正确，也不得从这两例强制推出某个未来恢复行为标签。

信息等价仅在同心智先验、同人物可得信息和同有效动作似然下约束心智边际。相关世界—心智先验及动作证据可能合理改变观察者对心智的推断；不能把这种修正处罚为泄漏。世界条件允许影响未来物理执行概率，信息等价不要求所有输出相同。

T1/T2从后验预测，不复制当前Q。`p_H=Σw r(z,H)`、`q_H(k)=Σw r(z,H)s(k|resume,z,H)/p_H`；零恢复质量时步骤条件分布未定义。不可用world_done硬删人物误以为未完成的步骤。

## 训练与验收计划

先结构化事件核验，再固定编码器监督AU/B/C/Q，接着真实行为头联合训练，最后加入信息等价和语义软约束。状态证据不足逐因子mask；P0脚本和P1实际行为分别报告。重采样不可微，当前不声称端到端可微SMC。

正式划分按 `base_story_id` 分组，同族A/B变体不得跨训练、开发和测试集合；P1还需按人物/任务族检查泄漏。超参数仅用开发集选择，校准集独立于测试集。v0.1种子未划分；v0.2适配已接入，实际train/dev/test为144/48/48条（72/24/24家族）。P0仅做流程诊断，不能推导泛化或校准结论；v0.3现为reviewed，本轮单独做冻结模型补充诊断，不合入主训练。

精确手算/对照误差目标1e-12；SMC以相同有限核跨至少20种子比较N敏感性、TV/预测误差分位数、最差例与模式丢失。开发起点N=128、ESS/N=0.5不是实测最佳。完整数据、语义模型和公平预算就绪前不调参宣称最优。

独立配置 `configs/a_ec_jmf_reference.json`只描述低层内核和隔离要求，不继承团队base的share_trunk。现有base不变；后续真实编码器必须明确世界/人物不共享污染语义。该JSON不是训练运行器，不能声称已按配置训练。

### 本轮有限参考实现的边界

采用固定结构语义而非关键词规则，精确核和SMC共用条件转移。接触、理解与采信分开；未接触事件不得触发心智进度重新推断；原目标与子任务分别记忆。观察者图只为未知恢复点提出可训练的记忆假设，保留UNKNOWN；不把整图复制成人物知识。旧参考核无明确资源证据时F保持UNKNOWN；神经版本通过隔离的观察者资源先验表达不确定性，不读取标签生成事实。人物自由文本解释和完整神经编码仍未实现。

训练先交付可执行的精确小状态参考：掩码NLL、严格信息等价JS、知识/语义约束与消融开关，以中央差分优化转移及行为头参数。该方案适合数值与流程诊断，成本随参数数增长；不冒充神经端到端训练，也不声称用SMC反传。零支持标签单独计数。T1采用决策机会hazard，T2单独建模未来未完成步骤，均未校准。

默认门控logit与行为系数只是开发起点，不是最优方案或实测人类参数。P0中的结构化U是已给证据，不能据此宣称学会从自然文本识别理解。A1—A6目前是实现开关准备，A2并非完整独立BCQ基线，A7和正式实验需C协调；没有运行消融对比或20种子评测。具体调用和C待定映射见A_INTERFACES.md。

## 风险与应对

|风险|触发/处置|验收/依赖|
|---|---|---|
|世界语义绕过AU|共享encoder、混合叙事、来源元数据|人物输入白名单、隐藏事实扰动、B证据复核|
|状态指数增长|多目标/分支完成集合|显式状态/转移预算；超限失败；SMC扩展|
|粒子模式丢失|稀有理解分支、尖锐似然、重采样|ESS+分支覆盖+多种子精确对照；失败再增N或改proposal|
|动作重复计证|同一动作同时改状态又独立加似然|声明生成模型及evidence role，只计一次概率因子|
|心智不可识别|无自述/证据|保留多假设/UNKNOWN监督mask，不宣称心理真值|
|主观/客观进度混淆|他人完成、人物未获知|两套完成集合与图，P04反例；不得共享硬mask|
|T2标签错位|P06嵌套动作、Q当未来首步|独立目标范围与resume条件mask|
|数据准备与接入不足|v0.1为16条draft种子；v0.2为240条reviewed脚本数据、已接A适配器，但A/C仲裁与获知时刻/P1仍缺|只可报告受控协议诊断；C公平实验和P1具备后再论真实有效性|
|接口漂移|B schema更新、C包装字段变化|版本化adapter，M1三方确认；未知版本拒收|

如果完整模型与等预算HMM/BDI/全历史提示持平，先简化定位机制误差，不堆网络。真实预测优势、新颖性和校准必须由团队正式数据/消融支持。工程契约检查不作为行为预测、性能优势或心理真值证据。


## 神经训练实现选择

选择已有CPU PyTorch的小型独立世界/人物GRU与MLP门控，沿用有限结构状态支持，以tensor乘积、index_add与归一实现可微精确联合滤波；不手写梯度，不以神经行为头旁路取代状态学习。bootstrap SMC仍是推断参考，不用于反传。本轮不引入大型语言模型或新文本数据依赖。

固定协议和复现入口见A_INTERFACES及configs/a_neural_p0.json。流程规定主批v0.2的A0–A6各20种子同预算P0联合训练、dev选择和冻结test诊断；v0.3已reviewed，单独报告。种子标准差只描述训练随机性，不能作为真实人类总体置信区间。A4本轮是事件软对齐和严格等价JS的具体子集；未声称完成所有研究损失或真实P1分阶段训练。最终结果以机器生成的results/p0/a_neural_v1为准。


B反馈的P02/P04冲突采用版本化纠偏，详见A_INTERFACES的`b-p0-v03/v2`：完成消息不再等价于撤销；局部动作不再确定性地撤回整个目标的终止承诺。后者新增一个可学习重新承诺门并保留两种假设，原始事件/标签仍由B仲裁。旧配置及检查点保持历史语义，修正版必须单独从头训练与报告，不能沿用旧分数；评价掩码与数据均不改。
