# A 算法决策：P1-only EC-JMF

## 当前决策与技术路线

当前主线为 `p1-ec-jmf/v1`：仅使用仓库公开派生 P1，保留 EC-JMF 的结构状态、可学习转移与联合滤波本体，不以普通分类头替代联合状态模型。全部状态网络参数随机初始化；不读取 P0 数据、P0 预训练权重、历史 Git 对象或旧模型。历史 P0、C 可见上下文和 READY 独立续答结果仅是历史材料，不能当本轮结果。

输入依次经过：P1 截止前事件适配 → 独立世界/人物文本词袋及 GRU → 分相结构转移门 → 可微有限联合滤波 → 后验混合的原生窗口恢复概率与条件步骤分布。文本表示实际进入转移门，而非仅在输出端旁接。词表只用 train 输入拟合；世界和人物使用独立文本参数，不共享混入后台事实的编码缓存。

每个事件分为客观世界、接触/理解、信念接受、人物动作四相，门概率条件于相应相位之前的状态；每相归并相同状态，保留相关的联合 B/C/Q 假设。人物可获得信息、当前理解、主观信念、目标承诺、人物已知进度与客观进度分别表示。理解采用当前状态充分统计，不把整段理解历史展开为不同状态。有限图最多12个步骤；没有依赖边不表示所有步骤已知可行。

现有有界中断栈结构保留，但本轮 P1 原生输入只有单目标，没有可核查的子任务身份与父目标关系；不编造子任务图，不宣称本轮数据验证了多目标中断恢复。分相滤波是结构假设，文本门可学习不等于已经验证自由文本语义理解。

## 长期认识与信息约束

客观事实、人物接触信息、人物理解信息与人物主观信念必须区分。后台事实可改变世界侧，不能单独作为人物已知的依据；接触不代表理解，理解也不代表采信。B 由人物可获得的信息、理解/采信与既往状态更新，允许误解、暂时未决及观察者证据不足。`UNRESOLVED` 与 `UNKNOWN` 不混用。

**人物没收到取消通知：** 后台已取消，但人物未收到通知、也没有其他线索。世界侧可记录取消；人物信念不能仅凭后台事实变成“已知取消”，也不能自动判为放弃。

**人物收到但误解通知：** 人物读到取消通知，却将其理解成暂缓。接触可为 ACCESSED，理解仍可为误解，信念可继续认为有效或未决；不得强制复制正确世界状态，也不得由该例强推未来行为标签。

人物侧只能消费自身动作或实际交付信息。IHBench 背景接触位指用户是否知情，不直接当 assistant 接触；背景保守留世界侧。已交付用户话语属于 assistant 可接触内容，理解仍未知。未明确接收的机器人环境变化保留不确定接触，不把故障发生当成已理解故障。A1 是故意取消信息边界的诊断，不是可部署的改善。

## 数据、目标与消融

IHBench 的所有 actor/任务统一按 READY conversation 的31/7/7组划分，不能沿用两个任务之间互相冲突的旧划分；只读取 READY 的分组，不训练其中 P0 状态记录。REBOOT 保持 episode 分组，InterruptBench 保持任务组。P1 标签与审计字段在模型输入外，排除未来回复、withheld tail、rubric、标签证据索引和未来 episode 长度。

训练目标是有效 V 的 NLL、mask 开启的恢复 BCE、条件步骤 NLL，以及时间因果的事件一致性辅助项。IH 的词法派生恢复/步骤标签是弱监督；REBOOT 恢复监督全为正例；InterruptBench 仅有 V。没有 B/C/Q/U 金标，也没有可报告的六状态总体准确率。

事件一致性由动作之前的联合先验及人物记忆预测下一已观察人物动作类型与已有步骤；不以当前动作之后的状态预测同一动作，不把动作硬转 B/C/Q 标签，不在后验中重复乘入动作似然。这是 P1 版跨时一致性实现，不是已监督的自由文本语义判断。

|变体|实际移除的机制|
|---|---|
|A0|完整 P1 EC-JMF|
|A1|接触与理解门控；人物流故意可见世界信息|
|A2|联合 B/C/Q 改为条件独立因子化|
|A3|人物滤波与编码只保留最近5个人物事件，客观世界保留|
|A4|移除上述时间因果事件一致性损失|
|A5|移除条件步骤训练损失，保留步骤头及相同评测|
|A6|标签无关固定转移门概率，预测头继续训练|

各变体须以非零路径、有效监督数量和实际训练记录说明机制是否被检验；不能以开关存在或独立续答模块的相同分数充当消融效果。

## 训练、输出与结论边界

正式配置定义 A0–A6、40轮、seed0–19、相同划分与配对批次预算；开发检查的单次 seed 不等于20种子正式实验。所有模型先完成 train/dev 选择，再评分已被历史查看过的 test；这属于重复诊断，不称新盲测。最小 dev 目标选模，包含 epoch0、并列保留最早轮次。最终 checkpoint 包含架构、词表、完整权重、配置与选模元数据，独立加载不查历史 Git。

恢复分布为 `p=Σ_z w(z) r(z,window)`；条件步骤为 `q(k)=Σ_z w(z) r(z,window) s(k|z)/p`。每潜状态使用原生窗口 Bernoulli，不将助手轮次、单回复或机器人尾段换成 P0 机会数或 Poisson 时间。零恢复质量时条件步骤未定义；步骤候选不按客观完成集合硬删，以保留人物进度可能落后的情况。

指标按来源与窗口分别报告。T1 衡量源窗口代理标签，T2 衡量有效 gold 恢复下的条件步骤；V 只在有效标签上评分。REBOOT 缺负类时 AUROC 未定义；F/A/B/C/Q/U 输出仅为潜变量诊断，不是准确率证据。公开模型/机器人数据不是实际人类效果，也不证明架构创新或一般校准能力。

从仓库根目录复现：`python -m models.ecr_mwm.p1_training --config configs/a_ec_jmf_p1.json`。正式产物约定为 `results/p1/ec_jmf/model.pt`、`report.json` 和 `README.md`。本文仅描述当前实现和预定正式协议；训练是否完成、执行了多少种子、实际结果均以生成后的正式报告为准，不能由配置推断已完成。

明确恢复事件与普通进度分开：REBOOT 截止前已经观察到的 `resume` 支持重新进入 ACTIVE 并更新当前步骤，即使先前潜状态为放弃或完成；普通 progress 不自动解除终止承诺。该转移不强制改写信念为 BELIEVES_VALID，也不把被屏蔽的恢复窗口样例作为未来恢复监督。
