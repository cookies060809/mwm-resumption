## 信息与状态

世界W与心智M分离。AU门控只能使用本事件交付证据和人物可获得内容，禁止共享包含世界事实的embedding/cache。A/U逐事件重判，不沿用上次“已读”。C/Q输入、人物任务图和完成集合也只来自人物信息；客观图不自动等于人物图。后台取消可以改变世界，不能直接把人物信念改成无效。

### 长期约束：世界事件、接触、理解与主观信念

后续设计和测试必须分别表示以下四个层次，不能以一个字段替代其余层次：

|层次|含义与更新依据|
|---|---|
|客观世界事件|记录实际发生的取消、完成、资源变化等事实及其证据；世界状态可据此更新，但不推出人物已知该事实。|
|人物接触证据|单独记录信息是否进入人物可获得的通道、是否有接收证据，以及证据是否不足。沿用A/D的接触证据含义，不把接触当作知识或理解。|
|人物理解情况|区分正确理解、误解与理解情况不明；U是设计中的内部辅助变量，不因已读或ACCESSED就赋为正确理解，也不把缺少理解证据自动当作误解。|
|人物主观信念|B依据人物实际可获得的信息、其理解/采信情况和既往信念更新；允许错误信念、暂时未决及证据不足，不直接复制客观状态。|

后台事实单独存在，不足以作为人物已经知道该事实的依据。人物接触信息，也不等于已理解、采信或记住内容。人物可获得的间接线索仍可提供更新依据；“没有收到某条通知”不意味着所有信念必须永远不变。`UNRESOLVED`用于有证据表明人物暂时无法判断的情况；`UNKNOWN`用于观察者缺乏足够证据，二者不混用。本段是长期建模约束，不新增正式schema字段，也不宣称理解模型已经实现。

**例一：人物没收到取消通知。** 后台已取消任务，但人物既未收到通知，也没有获得其他能察觉取消的线索。世界侧可以记录取消；人物侧不能仅凭后台记录就被确定为“已知取消”，也不能据此自动判定其已放弃。应保留与既有信息相容的信念或不确定性，而非强行填入正确答案。

**例二：人物收到但误解通知。** 人物确已阅读取消通知，却明确将其理解为“暂缓，等待进一步通知”。接触证据可以是ACCESSED，理解仍是误解；其信念可以继续认为目标有效或处于未决状态，不能强制改为“相信目标已取消”。具体判断须由其陈述、行动和可获得证据支持，不将该例写成所有人的固定反应规则。

今后的设计复核与测试应分别控制“世界是否变化”“人物是否接触”“人物如何理解”，检查以上两例是否保留客观/主观分离；不得只验证接触字段存在，便声称已验证理解或信念更新正确，也不得从这两例强制推出某个未来恢复行为标签。

信息等价仅在同心智先验、同人物可得信息和同有效动作似然下约束心智边际。相关世界—心智先验及动作证据可能合理改变观察者对心智的推断；不能把这种修正处罚为泄漏。世界条件允许影响未来物理执行概率，信息等价不要求所有输出相同。

T1/T2从后验预测，不复制当前Q。`p_H=Σw r(z,H)`、`q_H(k)=Σw r(z,H)s(k|resume,z,H)/p_H`；零恢复质量时步骤条件分布未定义。不可用world_done硬删人物误以为未完成的步骤。

## 当前模型与训练选择

独立世界/人物 GRU、结构化条件转移、PyTorch 可微精确联合滤波是本模型组成。
有限状态保留世界事实、人物可得信息、理解假设、信念、承诺、任务记忆和有界中断栈。
保留同一骨干权重及 tensor 名称，不把它作为旧模型部署；无中央差分或独立 SMC 运行入口。

上下文仅池化 valid & visible 的人物 proposal，再拼接末时刻人物记忆；有界残差
`2*tanh(MLP(state,context))` 加到原 hazard logit。可见不等于已理解或已采信，
这个行为支路不会改写 T3。原行为头的客观可行性特征仍可影响未来行为概率。
T2条件混合可能随每个状态的恢复概率变化；不得把当前Q当未来真实首步。

C 已按开发集均值选择 visible_context，seed0预先固定。本分支只接入这套完整方法，
不提供原头继续训练、机制平衡或 A1–A6 旧方法入口。训练冻结骨干，1993个新参数可训练，
总参数20370；40轮全批AdamW，包含epoch0候选、以未加权dev state+T1+T2损失最小选模，
并列保留较早轮次。可以重现 C 的残差训练，不宣称从零重训整个骨干。

单次seed与固定evaluation_seeds 0–19含义分开。C原来只做0–4，不能写成已有20种子证据。
全部train/dev选择完成后才可显式启用test评分；指标和标签屏蔽沿用既有A口径。
实际训练/加载命令与来源说明见 `results/p0/c_visible_context/README.md`。

## 语义与结论边界

沿用 b-p0-v03/v3：完成不等于取消，采信 completion_by_other 后按B约定为BELIEVES_VALID、
COMPLETED；终止后的孤立步骤保留继续/不继续两种假设；物理中断不要求消息理解；
承诺与活动相位分开；未关联消息不从单一目标推定归属。明确自述“仍有效/继续”可支持B，
不能简单由C标签反推B，也不能声称模型已学会自由文本理解。

P05-D6的A指自身进度通道，F未知涉及未观察的下一资源；关键事件焦点、消息目标及资源范围
未有完整公共输入契约。A仍是代理，六因子均值不能当已确认的B完整成绩；零支持不删。
结构化证据轨迹说明状态传播，不是新增attention贡献的解释。

P0 v0.3 是254条脚本构造数据，150/52/52，故事族不跨划分；test已有历史暴露。
C原头继续训练也达到同样硬判断准确率，不能独立归因于新模块。
