## 1. 最终研究方向及核心判断

### 1.1 一句话定义

研究**外部观察者**如何在连续、部分可观测的事件历史中，同时追踪：现实目标是否有效、人物知道什么、人物是否仍承诺原目标、任务进度与可恢复位置；据此预测人物在中断后**是否恢复原任务、恢复哪个步骤**。

### 1.2 与最初“三个心智变量”方案的关系

仍然使用**显式心智状态建模**，但算法创新不是简单向 MWM 增加“意图保持度、打扰敏感度、自行恢复概率”三个字段。

| 最初想法 | 本项目处理 | 理由 |
|---|---|---|
| 意图保持度 | 转化为**目标承诺状态的后验分布与动态更新** | 目标激活、衰减、挂起与恢复在认知科学和 BDI 中已有先例，单独增加一个分数不是新算法 |
| 打扰敏感度 | 作为扩展特征：中断时长、负荷、任务阶段、人物差异 | 受情境影响，不应预设是稳定的人物固有标量；核心方法先不依赖它 |
| 自行恢复概率 | **主要预测输出**，而不是未经定义的独立隐状态 | 必须指定预测窗口、观察条件和实际恢复标签 |

研究重心由**增加变量**转为**设计联合隐状态推断、信息可达性约束的事件更新、跨中断记忆与恢复步骤预测算法**。

### 1.3 正式研究问题（RQ）

**RQ：** 在相同可观测历史、相同基础模型与可比推理预算下，显式分离“现实事实—人物所知—目标承诺—恢复进度”，并以**认知可达性约束的联合动态更新机制**维护它们，能否比完整历史推理、规则目标管理、动态目标识别和原始 MENTIS 更稳定地预测跨中断的恢复行为与恢复位置？

主要研究边界：**单个人物、主要目标明确、可能包含插入任务的多步执行过程；先用结构化文本事件，后做多模态迁移**。这避免把视觉识别、目标发现、机器人控制的难度同时引入首个模型。

### 1.4 学术与竞赛定位

- **主类别：** “算法模型优化与突破”中的大模型与智能体、序列状态推断、语义理解、概率化推理及决策预测。
- **可扩展类别：** 具身智能/机器人中的人类状态预测；需有相应实验才能写入实际贡献。
- **不作为主类别：** 单纯行业应用或仅依靠新数据字段的系统开发。
- **申报措辞：** “拟提出并实现 EC-JMF 事件认知可达性约束的联合心智信念更新方法”，而不是“首次定义目标暂停/恢复”或“首次把意图加入世界模型”。

## 2. 真实技术贡献与创新性成立的论证

### 2.1 完整项目应交付的四项贡献

**C1｜问题与评测协议（Task & Benchmark）。** 定义“外部观察者下的跨中断恢复预测”任务，统一输入截断、客观/主观信息划分、人物目标承诺、恢复点、未知与删失标注，建立包含最小对照组和真实轨迹的评测集。该贡献是**任务/数据贡献**，不应冒充算法本身。

**C2｜信息可达性约束的联合状态更新器 EC-JMF（核心算法贡献）。** 提出并实现事件级动态推断机制：一条外部事件可以更新现实任务状态，但只有通过人物可接触、可理解的证据通道，才能直接支持对应的主观信念更新；人物承诺与恢复位置根据主观信念、历史目标记忆和任务条件联合更新。不能简单把世界事实复制到人物心智状态。

**C3｜跨中断承诺—进度联合预测。** 在同一状态信念下，联合预测未来窗口内是否恢复旧目标、恢复步骤，以及状态不确定性；处理“仍想做但暂不能做”“外界已取消但人物不知道”“任务已完成但人物未获知”等情形。

**C4｜机制可解释性与可复现证据。** 公开可复核的事件流、标签证据、基线与消融脚本、逐样例预测、算力成本、失败案例及跨场景评估；明确增益究竟来自认知可达性、联合更新、历史记忆还是额外上下文。

**优先级：C2 为核心算法贡献，C3 为任务驱动的方法功能，C1/C4 为可验证和可落地贡献。**

### 2.2 创新性为何在“立项/技术主张”层面有合理差异

| 已有研究已经解决或讨论过什么 | 我们不能再宣称什么 | 本项目需要实现的差异 |
|---|---|---|
| MWM 已含 goals、intentions 与动作条件化状态转移 | “首次在世界模型加入目标/意图” | **跨时刻联合状态信念、认知访问控制与恢复点追踪** |
| Memory for Goals / Borst 已研究目标激活、记忆竞争及恢复成本 | “首次设计意图衰减/恢复” | 将认知线索作为**状态更新机制的约束/特征**，而非声称原创心理理论 |
| BDI 2008 已设计挂起、重新考虑及恢复目标 | “首次设计 active/suspended/cancelled” | 从**外部观察**推断人物隐藏状态，而非代理直接管理自身已知任务 |
| 2017 滑窗动态目标识别已有“受打断后回到旧任务”案例 | “首次识别目标切换与恢复” | 保留被暂挂目标，并区别**取消、完成、不可执行和未获知事件** |
| SIPS / 贝叶斯目标识别已有后验目标追踪 | “首次概率化推断目标” | 学习**认知信息通道+目标承诺+恢复步骤**的联合转移，而非只跟踪单一目标候选 |
| 2024 goal solvability 模型已有目标可达性 | “首次考虑目标可行性” | **客观可行性与人物对可行性的信念分离** |
| INSIGHT / MWCRL 已结合意图、时序与动作预测 | “首次利用意图增强长时程动作预测” | **恢复事件与恢复步骤**的专门任务及跨事件约束 |
| GODR 2026 已提出目标失效、恢复契约与恢复位置 | “首次设计恢复契约/恢复点” | 由不完整外部证据**推断人类主观状态**，而非运行时直接维护用户目标 |

**创新性成立的准确表述：** 项目确定了一项可区分于上述具体研究设定的**算法设计主张**：针对外部观察者的认知可达性约束下，联合维护世界—人物信念—目标承诺—恢复进度的概率状态，以跨中断恢复预测为验证任务。其组成概念多有先例，所以**不能宣称已经证明独一无二或已有性能突破**；最终“方法有效”的实证论断由第 10 节的完整实验产生。研发方向和三人分工不再因此悬置。

### 2.3 核心方法的新意应落在什么位置

不是给语言模型附加四个标签，也不是“把完整聊天记录存成长期记忆”。必须实现以下**可调用的状态转移算子**并在同等信息下做机制消融：

1. **事件—接触证据分流：** 外部事实的发生、人物接触、人物理解/推断分别建模；
2. **受约束的联合更新：** 主观信念不能无条件吸收不可接触的事实；承诺与恢复进度随证据和任务状态联合演化；
3. **多假设后验：** 信息不充分时保留多个合理的信念/承诺状态，输出概率与置信度，而不是强制填一个确定标签；
4. **恢复点一致性：** 完成的步骤、尚未完成的步骤和任务依赖关系应在跨中断更新中保持一致。

若只是编码规则而没有可学习/可推断的联合更新和对照结果，只能称为结构化系统设计，不能把它包装为经过验证的算法突破。**其可执行参数化、反事实约束与训练/推断协议见第 5.5—5.13 节。**

## 3. 正式任务定义（Problem Formulation）

### 3.1 参与对象与观测条件

- **人物（target person）：** 执行原目标 `goal_id` 的主体；其心智状态并非直接可见。
- **外部观察者（model）：** 根据带时间戳的事件和证据做预测；可以看到某些人物未看到的外部事实，但必须记录其来源。
- **评测记录（privileged annotation）：** 事后可用于标注客观世界状态和真实动作，不能把未来事件泄漏给模型。
- **预测时刻 `t`：** 中断结束或指定的决策截断点。所有输入事件 `time <= t`；输出评价基于 `t` 之后的独立记录。

### 3.2 输入

设原目标为 `g`，任务步骤图为 `G=(K,D)`（步骤集合及依赖边），截至 `t` 的观察者历史为 `O_{1:t}`，预测范围为未来 `H` 个实际决策机会或固定时间窗口：

\[
X_t=(g,G,O_{1:t},t,H),\qquad O_{1:t}=\{e_1,\ldots,e_t\}.
\]

每条事件应有：`event_id、time、actor、event_type、goal_id、step_id、world_effect、observer_evidence、person_access_evidence、source、certainty`。**人物能否获知事件必须有独立字段，不得从世界事件发生直接推断。**

### 3.3 输出

1. **T1｜恢复事件：** `Y_{t,H}∈{resume, not_resume, censored}`，模型输出 `P(resume within H | X_t)`；`censored` 是评价状态，不是强制预测为“放弃”。
2. **T2｜恢复位置：** `Q^*` 为未来实际恢复时执行的首个原目标相关且尚未完成的步骤；模型输出条件概率 `P(Q^*=k | resume, X_t)`。
3. **T3｜状态信念：** 对第 4 节各状态因素输出离散标签分布及证据引用，未知时不能伪造确定状态。
4. **可选扩展 T4｜恢复延迟：** 仅在有真实时间戳、统一的起止定义与删失处理时研究；本版**不把合成文字中的“30 秒”当作认知恢复时延真值**。

### 3.4 “恢复”的操作性定义

人物先前确实开始过 `g`；中断期间停止推进 `g` 并转向其他活动；在 `t` 之后的观察窗口内，首次出现**可归属于 `g` 的、推动尚未完成步骤的实际行为**，则记录 `resume=1`。仅再次谈起该目标、返回原地点、心里仍想做但未行动，不自动算作行为恢复。由两名标注者按任务事件和动作证据确认；无法辨认时记 `UNKNOWN`。

### 3.5 两层数据结论不得混用

- **P0 受控协议诊断：** 人工脚本与明确规则给出预期行为，用于测试信息泄漏、因果因素敏感性、目标状态一致性；不能声称预测真实人类心理。
- **P1 真实行为预测：** 经许可的真实连续行为及中断恢复日志，实际行为和恢复时间由独立证据标注；才能报告现实恢复预测能力。

## 4. 正式状态标签体系与标注手册

定义联合候选状态 `Z_t=(V_t,F_t,A_t,B_t,C_t,Q_t)`。其中 **V、F 是世界/任务状态，A 是证据接触状态，B、C、Q 是待推断的人物认知/意图/进度状态**。不要将六者统称为六个“真实心理变量”。

| 字段 | 标签 | 严格含义与标注证据 |
|---|---|---|
| `V` 客观目标有效性 | `VALID / CANCELLED / FULFILLED / UNKNOWN` | 后台记录、物理任务结果或其他独立事实；不依赖人物知不知道 |
| `F` 当前客观执行可行性 | `READY / BLOCKED / UNKNOWN` | 工具、资源、权限、依赖步骤是否允许继续；“有效”可以同时“受阻” |
| `A` 对关键事件的接触证据 | `ACCESSED / NOT_ACCESSED / UNCERTAIN` | 已读/听见/看见/操作等证据；接触不必然等于理解 |
| `B` 人物主观信念 | `BELIEVES_VALID / BELIEVES_INVALID / UNRESOLVED / UNKNOWN` | 自述、明确行动或脚本中的可核查信息；不可直接从客观 V 复制 |
| `C` 原目标承诺 | `ACTIVE / SUSPENDED / ABANDONED / COMPLETED / UNKNOWN` | 正在推进、暂挂仍意图继续、明确放弃、认为已完成；“暂时未行动”不自动等于放弃 |
| `Q` 主观恢复步骤 | `step_id / UNKNOWN / NOT_APPLICABLE` | 人物已掌握的当前未完成步骤；恢复点可能不同于客观最优步骤 |

**额外记录，不并入互斥状态标签：** `interruption_start/end`、`interruption_duration`、`interrupting_task`、`demand_level`、`goal_priority`、`resume_cue`、`deadline`、`parent_goal_id`、`source_confidence`、`annotator_id`。

### 4.1 六条硬性标注约束

1. **客观与主观分离：** `V=CANCELLED` 不推出 `B=BELIEVES_INVALID`。
2. **接触与理解分离：** `A=ACCESSED` 不自动推出人物正确理解通知；需要额外证据。
3. **有效与可执行分离：** `V=VALID, F=BLOCKED` 完全合法。
4. **状态与行为分离：** `C=SUSPENDED` 不说明未来 `H` 内一定恢复。
5. **未知与删失分离：** `UNKNOWN` 为当前证据不足；`censored` 为实际后续行为观察不足。
6. **证据链强制保存：** 每个非未知标签都应能对应一个或多个 `evidence_event_ids`；不允许使用未来结果反推时刻 `t` 的人物信念。

## 5. 候选核心算法与技术路线

### 5.1 算法结构

**术语统一：** ECR-MWM 指完整系统，**EC-JMF** 指其中可独立训练、调用、比较和消融的联合心智状态更新算法；第 5.5—5.13 节为其规范实现方案。


```text
连续事件与人物行为流
       │
       ▼
① 事件解析 / 时间与证据溯源 ───────┐
       │                           │
       ▼                           ▼
② 世界任务状态更新 W_t       ③ 人物信息可达性门控 A_t
       │                           │
       └────────────┬──────────────┘
                    ▼
④ 受约束的主观信念更新 B_t（保留多种可能解释）
                    │
                    ▼
⑤ 目标承诺 C_t + 任务进度/恢复位置 Q_t 联合更新
                    │
                    ▼
⑥ 后验信念 b_t(Z_t) 与跨中断记忆
                    │
          ┌─────────┴──────────┐
          ▼                    ▼
⑦ H 内恢复概率         ⑧ 条件恢复步骤分布
```

### 5.2 核心建模

令 `e_t` 为新事件，`a_t` 为该事件对人物的可达性证据，`b_t` 为对联合状态的后验：

\[
b_t(z_t)\propto p_\theta(o_t\mid z_t)
\sum_{z_{t-1}}
T_\theta(z_t\mid z_{t-1},e_t,a_t)b_{t-1}(z_{t-1}).
\]

上述一般滤波式**不是原创贡献**。待实现的技术点是具有语义约束的 `T_θ`：

- `T_world`：外部事件如何改变真实目标有效性和可执行条件；
- `T_access`：哪些证据有可能到达人物、到达证据是否可信；
- `T_belief`：主观信念如何受**可达证据**更新，保留误解、未获知及信息冲突的概率；
- `T_commitment`：在主观信念、目标记忆及任务条件下如何更新承诺；
- `T_progress`：在人物认为已完成的步骤与依赖图上维护恢复位置。

具体实现选用**神经事件编码器 + 结构化概率状态更新 + 约束正则化**；基础语言模型负责从自然语言产生事件候选与语义特征，结构化更新器负责状态递推与概率输出，而不是让大模型每一步无约束地重写整段记忆。可先在小离散状态下实现精确/近似枚举，随着状态扩大改用粒子或变分近似。

### 5.3 要落实的三项机制与损失

**M1 信息可达性门控：** 对 `event -> person_belief` 的直接更新引入可学习接触/理解门控。可达性不确定时对“接触/未接触”两种可能做概率混合，而非强制认为知道。

**M2 目标承诺—进度一致更新：** 维护历史未完成目标记忆以及任务依赖。暂停、继续、终止与步骤推进要同时受到证据约束；即使最新动作属于插入任务，也不自动遗忘旧目标。

**M3 对照一致性训练：** 在匹配的最小对照对中，约束模型对**人物可获得信息发生实质变化**的样例给出合理的信念差异；对仅外部后台变化且没有任何新的可察觉线索的样例，不应凭空改变人物已知事实。注意只约束与具体标签有逻辑关系的输出，不要求所有未来行为分布对世界变化绝对不变。

计划总目标：

\[
\mathcal L=\mathcal L_{resume}
+\lambda_q\mathcal L_{step}
+\lambda_z\mathcal L_{state}
+\lambda_e\mathcal L_{epistemic}
+\lambda_c\mathcal L_{consistency}
+\lambda_p\mathcal L_{calibration}.
\]

- `L_resume`：带真实标签的恢复预测损失（可用二元交叉熵；删失样例需另外适配）；
- `L_step`：只对真实发生恢复且恢复步骤可标注的样例计算；
- `L_state`：仅对有足够依据的状态标签监督，UNKNOWN 作掩码或显式未知类；
- `L_epistemic`：限制不合理的“不可接触事件 → 主观知识确定更新”路径；
- `L_consistency`：跨时间及成对样例语义一致性；
- `L_calibration`：概率校准评估或专门校准项，避免只优化分类准确率。

具体网络规模、训练超参数、约束软硬程度与推断预算以正式实现配置文件为准，不在项目文档预设实验结论。

### 5.4 集成至 MWM / MENTIS

- 保留 MWM 的物理—心智双状态理念和原有基线，不宣称其没有 goals/intentions。
- 首先开发**独立可运行的事件状态更新器**，在符号事件或文本事件上实现 T1/T2/T3。
- 正式系统中增加 `session_id、goal_id、event_log、state_belief、evidence_trace` 等跨时刻接口，将更新器接入 MENTIS 的状态解析/转移与决策环节。
- 同时保留发布版 MENTIS、不带认知约束的“等量历史记忆 MENTIS”和“结构化目标提示 MENTIS”，防止把额外 context 的收益错误归因于新算法。
- 版本固定并记录输入、模型、提示、temperature、token 数、状态快照、预测和异常；论文中区分“公开实现复现”与“论文中无法公开重现的 oracle 分析”。

### 5.5 EC-JMF：算法设计目标与真正的技术边界（新增）

**核心命题：** 给定外部观察者所见事件 `e_t`、其证据来源、人物可能接触的线索和先前的联合状态后验 `b_{t-1}`，输出**当前联合后验** `b_t`，而不是将外部事实直接改写为人物内在信念。以该后验预测未来 `H` 内的实际恢复行为及首次恢复步骤。

EC-JMF 的新意**拟集中在可学习的“证据可达性—信念—目标承诺—主观步骤”联合转移参数化，以及受控反事实信息等价约束**。**不声称**发明 POMDP、贝叶斯滤波、粒子滤波、BDI 生命周期或一致性正则化。学术贡献的强弱必须最终通过普通滤波、结构化提示、BDI 与无约束神经转移等基线/消融识别。

**状态与观察的角色不可混淆：**

- `W_t=(V_t,F_t,P_t^world)`：客观目标有效性、资源/可行性与世界任务进度；客观事实可能只被观察者部分获知，故仍可用概率表示。
- `M_t=(B_t,C_t,Q_t)`：人物主观信念、目标承诺、主观恢复步骤；是主要隐藏的心智因素。
- `A_t`：人物是否**接触**相关事件的潜在状态；第 4 节标签 `ACCESSED/NOT_ACCESSED/UNCERTAIN` 是可观察的**证据标注**，不能将标注的不确定性直接当真实人物状态。
- `U_t`：新增的**内部辅助潜变量**，表示接触后是否理解/采信，取 `未接触/接触未理解/接触且理解` 的条件分支；它**不是替换第 4 节六维标签接口**，也不能在无证据时作为真实认知标签。
- `D_t`：事件交付证据（人物屏幕、现场可见线索、音频通知、行动反馈等）；`E_t^world`：可由外部观察者记录的客观事件证据。二者可以不同。
- `O_t^{act}`：人物当时实际做出的可观察行为，供**后验修正**；不得含预测截断 `t` 之后的行动。

**任务标签：** P0 中预先设定的“脚本人物规则”仅用于协议/逻辑诊断；P1 中真实人物的恢复行为才是行为预测的主要经验监督。对 P1 缺乏自述或可验证证据的 `B/C/Q`，保持未标注并遮蔽状态损失。

### 5.6 因子化事件转移：可执行的概率图分解（新增）

沿用 `Z_t=(V_t,F_t,A_t,B_t,C_t,Q_t)`。为表达人物可能理解/误解某事件，在转移时对 `U_t` **边缘化**；对因任务数变大产生的联合离散状态组合，采用近似推断而非强制输出单一标签。

先从事件语义编码器获得：

\[
\mathbf h_t=\mathrm{Enc}_{\phi}\!\left(e_t,\mathrm{source}_t,\Delta t,\mathcal G,\mathrm{evidence}_t\right),
\]

其中编码器可用**固定文本嵌入 + 小型 MLP/GRU**起步；若直接使用 LLM，则固定模型版本和提示、记录解析正确性与 token 成本。结构化数据可跳过 LLM 解析器，以隔离推断机制的效果。

采用以下**拟实现**的有向条件化转移，注意这是一种模型参数化选择，**不是一个新的概率论定理**：

\[
\begin{aligned}
&T_{\theta}(z_t,u_t\mid z_{t-1},e_t,D_t,\mathcal G) \\
&=T_{\theta}^{W}(V_t,F_t\mid V_{t-1},F_{t-1},E_t^{world})\\
&\quad\cdot T_{\theta}^{AU}(A_t,U_t\mid A_{t-1},D_t,\mathbf h_t)\\
&\quad\cdot T_{\theta}^{B}(B_t\mid B_{t-1},U_t,\widetilde e_t^{person})\\
&\quad\cdot T_{\theta}^{C}(C_t\mid C_{t-1},B_t,Q_{t-1},\xi_t^{person})\\
&\quad\cdot T_{\theta}^{Q}(Q_t\mid Q_{t-1},C_t,B_t,\mathcal G_t^{person}).
\end{aligned}
\]

**关键约束**：`\widetilde e_t^{person}` 只能是人物可获得的事件内容（含直接证据及可用间接线索）。`\xi_t^{person}` 与 `\mathcal G_t^{person}` 也必须基于人物当时可获得的任务信息。模型对客观 `F_t` 的更新可用于**预测动作是否物理可完成**，但不允许把人物不知道的 `F_t` 变化直接写进其信念或承诺。遇到来源冲突时，保留概率分布而非强行设为确定事实。

接触与理解门控可实现为：

\[
\pi_t(a,u)=\mathrm{softmax}\big(f_{\theta}^{AU}(\mathbf h_t, D_t, a_{t-1})\big),
\]

\[
P(B_t\mid B_{t-1},e_t,D_t)
=\sum_{a,u}\pi_t(a,u)\,T_{\theta}^{B}
(B_t\mid B_{t-1},\widetilde e_t^{person}(a,u)).
\]

这里“未接触”分支并非永不更新人物信念：若有**独立可获得的间接线索或可观察行为**，仍可更新；但不能因为观察者看到后台取消消息，就直接把该消息当作人物看到的输入。

**实现接口（统一工程契约）：**

```python
updated = filter.update(
    prior_belief=previous_state_particles,
    world_event=event_record,
    delivery_evidence=person_access_record,
    observed_person_action=action_until_cutoff,
    task_graph=task_graph,
    timestamp=event_time,
)
# updated: particles, weights, marginal_state_probs,
# evidence_trace, candidate_resume_prob, conditional_step_probs
```

### 5.7 事件后的后验修正与序贯蒙特卡洛（新增）

新事件可能与人物真实动作相矛盾，因此不能只做前向规则演化。EC-JMF 维护 `N` 个粒子 `\{(z_t^{(i)},w_t^{(i)})\}`，将本轮观测到的实际动作作为**似然证据**更新权重。

\[
\widetilde z_t^{(i)},u_t^{(i)}\sim
T_{\theta}(\cdot\mid z_{t-1}^{(i)},e_t,D_t,\mathcal G),
\]

\[
\widetilde w_t^{(i)}\propto
w_{t-1}^{(i)}\cdot
p_{\theta}\big(O_t^{act}\mid \widetilde z_t^{(i)},\mathcal G\big),\qquad
w_t^{(i)}=\frac{\widetilde w_t^{(i)}}{\sum_j\widetilde w_t^{(j)}}.
\]

**流程**：每个事件先传播世界状态和人物心智候选，再根据当时**已观察**的行动加权；计算有效粒子数 `ESS=1/Σ(w_i²)`，低于开发集设定阈值（起始参考 `N/2`）时进行系统重采样；随后提取状态边际分布、证据路径和恢复预测所需特征。

重要边界：**SMC 是借鉴自 SIPS 等工作的既有工具，而不是 EC-JMF 的原创性来源。** 首版可以用小状态空间的**精确枚举/HMM**校验粒子输出，再接神经概率转移。粒子重采样通常不可直接微分，建议先监督训练转移子模块、**推断时用 SMC**；不应未经实现就声称完成端到端可微分粒子训练。

**输出头**从过滤后的联合后验而非直接从答案文本产生：

\[
\widehat p_{t,H}=\sum_iw_t^{(i)}
\,p_{\psi}(Y_{t,H}=1\mid z_t^{(i)},\mathcal G,H),
\]

\[
\widehat q_{t,H}(k)=P(Q^*=k\mid Y_{t,H}=1, O_{1:t}),
\]

第二个输出应在粒子预测的**未来恢复事件**条件下求条件化分布；不应直接拿 `Q_t` 当前标签与未来恢复行为无条件等同。若恢复事件概率很低，必须对步骤分布的不确定性和适用范围加注释。

### 5.8 两类反事实最小对照与训练约束（新增）

**类型 I｜不可见世界变更（信息等价）**：两条样例的外部世界事实不同，但人物初始心智假设、截至 `t` 的**全部可获得信息及可观察行动**均相同，而且隐藏事件不产生任何其他人物能察觉的后果。在这些**受控条件**下，人物心智后验不应仅因为外部后台事实不同而变化。

\[
\mathcal L_{inv}=
D_{JS}\left(
  b^{ment}_{\theta}(h),
  b^{ment}_{\theta}(h')
\right),
\quad h\sim_{person}h'.
\]

这里 `b^{ment}` 只边缘化到 `(B,C,Q)` 等**人物心智状态**，**不约束客观 `V/F` 后验相同**，也不强制有不同物理执行条件的未来成功率一致。这种不变性是在**严格匹配初始条件、没有潜在线索、背景外生性成立**时的模型约束，不是关于所有真实人类认知的无条件定理。

**类型 II｜人物信息变化（应有辨识）**：世界事实和其他条件相同，人物收到/理解一条可信消息与完全没有获知时，模型应按**标注证据**产生合理的信念后验差异。可使用有标签的监督交叉熵或成对目标分布约束，**不一律强迫行动标签改变**。不宜用无根据的“必须拉开固定 KL 距离”代替真实标签。

**为何同时需要 I 和 II？** 仅有 I，模型可能学成“永不更新”；仅有 II，模型可能凡是看到“取消”等词就更新人物信念。二者共同约束的是**哪些外部信息允许进入人物状态，以及进入后如何更新**。与 MWCRL 等“对时间顺序打乱做对比”的方法不同，EC-JMF 的受控变化对象是**信息的接触/可达性**，但其新颖性仍须和一般对比/一致性正则、动态认知逻辑及神经 POMDP 进行消融和原文比较。

### 5.9 训练目标、监督来源与删失处理（新增）

建议把第 5.3 节的总目标落实成以下**可计算版本**（系数 `λ` 由开发集调优，不预设最佳取值）：

\[
\begin{aligned}
\mathcal L ={}& \mathcal L_{state}^{masked}
+\lambda_r\mathcal L_{resume}
+\lambda_q\mathcal L_{step}^{masked}\\
&+\lambda_i\mathcal L_{inv}
+\lambda_s\mathcal L_{semantic}
+\lambda_k\mathcal L_{knowledge}.
\end{aligned}
\]

| 目标项 | 具体计算 | 使用何种数据与避免的错误 |
|---|---|---|
| `L_state^masked` | 对有独立证据支持的 `V/F/A/B/C/Q` 标签作分类负对数似然；无可靠标签时逐因子掩码 | P0 脚本标签可用于协议诊断；P1 不得把研究者猜测当客观心智标签 |
| `L_resume` | P0 是脚本行为标签的 BCE；P1 使用实际发生恢复且观察覆盖整个窗口的行为标签 | **P0 结果不能写成真实人类恢复预测能力** |
| `L_step^masked` | 对确已发生恢复、可标注的未来首次步骤做条件分类交叉熵 | 未恢复及步骤不可见样例不计算该项 |
| `L_inv` | 严格信息等价的成对状态后验 JS 散度 | 仅在匹配条件成立且观测等价时计算；排除世界状态 |
| `L_semantic` | 任务步骤合法性、完成顺序与状态冲突的软约束代价 | 硬约束只用于逻辑/时间/任务图必然不可能的情况 |
| `L_knowledge` | 当证据明确证明信息未接触且无旁路线索时，对未经支持的主观事实跳变给出处罚 | 不把“行为不符合常理”设成绝对违规；允许合理误解和推断 |

**P1 右删失规则**：未来 `H` 未观察完整不能直接记为 `not_resume`。首版在固定窗口二分类时**剔除尚未覆盖完整窗口且未出现恢复事件的样本**，单独报告删失比例；如需利用这些样本，再采用离散时间 hazard/生存似然并记录每段风险暴露时间。校准以独立验证集温度缩放或类似方法进行，同时报告 Brier/ECE；无充足样本不声称校准可靠。

**工程建议的训练顺序：**

1. **S0 管道校验**：结构化事件 + 明确规则/精确滤波，测试 P01–P08、状态不可能组合、未来泄漏测试。
2. **S1 学习转移**：以有依据的状态转移标签训练 `T^AU/T^B/T^C/T^Q`，先固定事件语义编码器，避免所有参数同时漂移。
3. **S2 联合行为训练**：以 P1 真实行为监督 T1/T2，状态标签缺失因子掩码；对 P0 只报告受控脚本结果。
4. **S3 约束优化**：加入 `L_inv` 和一致性项，做 `无约束 / 仅 I / 仅 II / I+II` 四组消融，检查收益是否只是增大训练样本数量。
5. **S4 推断与校准**：启用粒子滤波并复核与小状态精确推断的一致性，在独立集上校准恢复概率。

### 5.10 可运行的算法伪代码（新增）

```text
Algorithm EC-JMF: Event-Driven Joint Mental-State Filtering
Inputs:
  event_stream e[1:t], task_graph G, initial_belief b0,
  person_access_evidence D[1:t], observed_actions a[1:t],
  particle_count N, prediction_horizon H
Outputs:
  posterior b_t, resume_probability p_H,
  conditional_resume_step_distribution q_H, evidence_trace

1. Initialize particle set {(z0[i], w0[i])}_{i=1..N} from b0
2. For k = 1..t:
     2.1 Parse e[k] into observer-world evidence and
         person-available evidence; preserve event provenance.
     2.2 For each particle i:
           - sample/propagate objective world state (V, F)
           - infer access A and comprehension U
           - update subjective belief B using person-available cues
           - jointly update commitment C and subjective progress Q
           - compute observed-action likelihood ONLY using a[<=k]
           - update particle weight
     2.3 Normalize weights; record likelihood and contradictions.
     2.4 If ESS below threshold: resample particles.
     2.5 Save posterior marginals and evidence trace at time k.
3. Predict future resume event within H by marginalizing particles;
   predict first resume step conditional on a resume event.
4. Return calibrated probabilities and current posterior.

Training:
   masked state supervision + actual-behavior targets
   + information-equivalence counterfactual consistency
   + task-graph/temporal semantic constraints.
```

**重要限制**：该伪代码是开发规格，并非已运行软件；行为似然计算只使用实际已有行动，绝不把 `t` 之后标签或测试集未来事件用于更新 `b_t`。

### 5.11 网络、数据与计算的默认起步配置（新增）

| 组件 | 第一版可执行选择 | 后续研究变化与必须记录的成本 |
|---|---|---|
| 输入事件 | 结构化 JSON，固定事件类型/证据来源/人物可接触标签 | 文本 LLM 解析时，独立报告解析准确度与 token 成本 |
| 事件编码 | 事件类别 embedding + 时间/来源/人物信息标志 + 小型 MLP；可用冻结语言特征 | 避免把更强的 LLM 语义能力算成状态算法贡献 |
| 状态转移 | `T^W/T^AU/T^B/T^C/T^Q` 各自参数化分类分布；小规模因子共享底座 | 记录各子模块参数、优化器、数据依赖及不确定性 |
| 约束 | 必须成立的任务图/时序约束用状态 mask；认知倾向用软约束 | 禁止将“取消就一定放弃”写成硬规则 |
| 推断 | 先用小域精确枚举作数值正确性测试，再用 SMC（`N=64/128` 为待调试起点） | 报告 ESS、粒子耗尽、重采样、时延与粒子数敏感性 |
| 参数学习 | 子模块先用监督交叉熵训练；行为头随后联训；必要时再研究可微近似推断 | 标记哪些步骤是真正端到端，不能以推断时 SMC 冒充可微训练 |
| 预测窗口 | 首版 `H=3` 个真实决策机会；之后多窗口（例如 1/3/5） | 真实时间预测必须另有可靠时间戳与删失建模 |
| 校准 | 开发集选超参；独立校准集后处理温度 | 严格分隔同故事家族/同人物数据与训练集 |

**停止复杂化准则**：若全历史 + 结构化提示、BDI 状态机、普通 HMM/SMC 与 EC-JMF 持平，优先简化模型并定位未解决错误，而不是继续堆网络层或损失函数。该准则用于诚实评价技术贡献，不改变团队既定研究任务。

### 5.12 标准方法竞争与最小消融清单（新增）

| 比较方式 | 需要真正排除的替代解释 | 对应已有工作/技术 |
|---|---|---|
| **完整历史直接预测** | 增益是否只是记住了更多历史 | LLM full context / MWM direct |
| **同基座完整历史 + 结构化提示** | 增益是否仅是语义拆分/Prompt 改写 | Structured prompting |
| **规则 BDI 生命周期** | 暂停、取消、恢复规则本身是否已经足够 | BDI 2008、GODR 2026 |
| **五事件滑窗目标识别** | 是否只是利用更早的动作或旧目标记录 | Dynamic Goal Recognition 2017 |
| **普通 HMM / SMC（相同状态数量）** | 多假设概率跟踪是否已经给出全部收益 | BToM、SIPS 与传统滤波 |
| **无信息可达性因子的 EC-JMF** | 是否只是联合状态和参数数量更多 | 组件消融 |
| **有访问字段、无反事实约束** | 信息等价对照损失有没有额外帮助 | 一般神经状态空间模型/一致性学习 |
| **独立估计 B/C/Q、无联合消息传递** | 联合依赖是否不可替代 | 多任务分类器 |
| **相同新训练样本、无成对关系损失** | 收益是否仅因增加训练数据 | 数据增强对照 |
| **相同观察、预算下的原 MENTIS 与记忆版** | 接入 MWM 后是否仍有新增能力 | MWM 官方发布版与公平集成 |

必须分别报告 P0 逻辑一致性、P1 真实行为预测、模型复杂度/推理开销和跨人物/任务泛化；不能仅在自造的最小对照题上显示优势就宣称“真实心智世界模型创新已成立”。

### 5.13 EC-JMF 的具体创新声明、已有先例与验收证据（新增）

| 拟申报的算法贡献 | 可追溯的成熟基础 | 需要由**我们自己的实现/实验**证明的事实 |
|---|---|---|
| **C2-a** 受认知可达性约束的联合状态转移算子 | 动态认知逻辑、POMDP、BToM、MWM | 保持同样输入和参数/预算条件下，世界事实不会无证据泄漏到人物信念后验，同时恢复预测不劣化 |
| **C2-b** 跨中断的承诺—主观恢复步骤联合滤波 | Memory for Goals、Borst、BDI、SIPS、GODR | 比独立分类、BDI、普通 HMM/SMC 更准确地推断状态及恢复步骤；消融有可重复差异 |
| **C2-c** 人物信息等价反事实一致性学习 | 一般一致性正则、对比学习、MWCRL 的时序对比 | 在模板外与真实任务中减少未可见事件导致的主观信念误更新；与等量数据增强对照仍有额外收益 |

**最终学术口径**：创新**位置和拟实现的技术机制**已经确定，算法**确切新颖性**取决于相比已有工作的实现差异，算法**有效性**取决于真实可重复的基线和消融；在成果报告中严格区分这三项。明确拒绝“首次提出概率滤波/信念更新/任务恢复状态”的不实措辞。

## 7. 必须比较的强基线与实现原则

| ID | 基线 | 简介与作用 | 具体实施 |
|---|---|---|---|
| B0 | 最近动作/最近目标（Recency） | 最简单的短期行为启发式；排除“只看最近事件也够用” | 最近可识别活动 → 下一目标/步骤 |
| B1 | 固定 5 事件窗口（Sliding Window） | 对应 2017 动态目标识别方向 | 每次只保留末 5 个事件，结合可运行目标匹配/预测器；报告与 SET-PR 原文实现差异 |
| B2 | 完整历史直接预测（Full History LLM） | 最关键的信息量对照 | 与 ECR-MWM 使用**完全相同**的历史事件、基座、候选输出和评价切片 |
| B3 | 完整历史+结构化 Prompt | 排除字段格式化和提示工程收益 | 明确列“目标/人物可能知道/任务进度”，不安装新的状态更新器 |
| B4 | 持久目标记忆（Persistent Memory） | 排除“只增加长期记忆”即可解决 | 保存旧目标、最近证据和已完成步骤，不加认知可达性更新 |
| B5 | BDI 规则生命周期 | 强规则基线，排除 active/suspended 等标签的普通工程收益 | 明确挂起、继续、取消、前提检查的可执行规则；人物信息采用证据规则 |
| B6 | 激活/线索/时长基线 | 排除认知记忆简单模型收益 | recent activation、衰减、cue、duration、demand 组成参数化预测器 |
| B7 | 简化贝叶斯目标跟踪 | 排除普通概率化 belief tracking 的收益 | 对目标候选状态做 HMM/粒子近似；不加入全部联合认知约束 |
| B8 | 官方公开版 MENTIS | 证明相对选定 MWM 基线的增量 | 固定代码 commit、模型配置、调用预算；如实记录其开放实现边界 |
| B9 | 等量历史/记忆增强 MENTIS | 排除 MENTIS 获益只是上下文变多 | 输入同长度摘要和目标日志，但不使用新转移算法 |
| B10 | **ECR-MWM（完整方法）** | 待提交主模型 | 联合状态更新 + 信息可达性 + 恢复位置预测 |

**可选拓展对照：** 在匹配的结构化符号任务中增加 SIPS/BToM 机制复现；在视觉阶段对 INSIGHT、MWCRL 进行同模态或明确标注为迁移性比较。不可把几行提示词称为这些研究的严格复现。

### 公平比较六项规定

1. 相同任务定义、相同 P0/P1 划分、相同截止时刻、相同关键事件可见性。
2. 同基座语言模型及尽量相同采样设置；记录 prompt tokens、总推理 tokens、时延、算力与成本。
3. 数据划分按 **`base_story_id` 与人物/任务族** 分组，同一个故事的 A/B 变体禁止分到训练与测试两侧。
4. 规则/结构化算法还需报告参数和开发集调参过程，防止 test leakage。
5. 除效果指标外必须给出置信区间、逐样例预测、失败类型和重要性消融。
6. 如果 MENTIS 作者论文 oracle 中间标注未发布，不得以自行生成的标签冒充论文 gold 或声称复制其 oracle 实验。

## 8. 正式对照样例设计

### 8.1 核心样例原则

**最小对照对（Minimal Pair）**在两条故事中只改变一个可追溯因素，其他任务、动作、时长、环境和预测截止点尽量相同。对每条记录分别保存 `factual_world_state、person_access_evidence、scripted_policy、expected_P0_output、actual_P1_outcome`；P1 尚无真实结果时写 `null`，不能凭 P0 规则生成实际恢复标签。

### 8.2 八组必需场景（至少 16 条原型）

| Pair | 固定条件 | A/B 唯一或主要变化 | 主要检验维度 | 在 P0 脚本策略下的预期 |
|---|---|---|---|---|
| P01 取消认知 | O17 订单已取消、人物接电话返回原台 | A 已看且确认取消；B 完全未接触通知 | **客观事实 ≠ 人物信念** | A 不继续；B 按旧信息继续包装 |
| P02 旧目标承诺 | 最后五个事件和当前动作相同 | A 早前明确“稍后继续”；B 早前明确“原任务撤销” | 长期承诺 vs 滑窗 | A 恢复；B 不恢复 |
| P03 恢复位置 | 同一中断时长、目标及工作台 | A 中断前已打印运单；B 中断前未打印运单，人物知情 | 未完成步骤指针 | A 跳过打印；B 从打印步骤继续 |
| P04 他人代完成 | 同事已完成主任务、人物回来 | A 人物被明确告知；B 没有获知 | 完成事实与信念分离 | A 避免重复；B 可能重复推进 |
| P05 暂时不可执行 | 目标一直有效且人物意图继续 | A 所需工具已恢复；B 仍缺失工具，人物可见 | 承诺 ≠ 可执行性 | A 执行原步骤；B 保持目标但等待/找工具 |
| P06 嵌套中断 | A→插入 B→又被 C 打断 | A 结束 C 时 B 已完成；B 结束 C 时 B 尚未完成 | 目标层级与恢复顺序 | 前者可返回 A；后者先完成 B（按明确优先规则） |
| P07 未来泄漏负对照 | 截止时刻 `t` 输入完全一致 | 只改变 `t` **之后**发生的真实结果 | **不可预知未来** | 两条记录在 t 的预测分布应相同；未来标签可不同 |
| P08 接触但误解 | 同一取消通知、相同客观任务状态 | A 已读且正确理解；B 看过但明确误读为暂缓 | 接触 ≠ 理解 | A 停止；B 根据误读状态决定暂停，而非直接取消 |

### 8.3 P01 完整事件脚本

**共同事件**（截断点 10:05）：

```text
10:00 e01 员工开始 O17：核对地址（完成）→ 包装（进行中）→ 打印运单（未做）。
10:01 e02 员工转去接电话，原目标暂挂。
10:03 e03 客户在后台取消 O17，客观订单状态为 CANCELLED。
10:05 e05 电话结束，员工返回同一工作台；此时预测未来三个决策机会。
```

**A 版本唯一增量：** `10:04 e04` 员工打开通知并明确确认“订单已取消”。  
**B 版本唯一增量：** `10:04 e04` 通知只在人物不可接触的后台队列中，且无任何可见线索。  
**P0 预期：** 按已定义的“仅依据人物已知信息继续任务”的脚本策略，A 不恢复，B 恢复包装。  
**注意：** 现实员工不一定遵守此策略；P1 必须观察真实动作才能得出结论。

### 8.4 P03 完整恢复点脚本

```text
原任务：检查地址 → 包装物品 → 打印运单 → 交接快递。
共同：中断前员工正在推进 O17；10:10 被电话打断；10:13 回到台面。
A：10:09 人物已经打印且核对运单，知道该步骤完成。
B：10:09 人物正准备打印，但设备尚未执行，知道该步骤未完成。
```

**P0 预期：** 两组都可能恢复订单，A 的首个未完成步骤为“交接快递”（假定包装亦已完成），B 为“打印运单”。样例正式入库前须补全包装已完成的共同事件，避免步骤依赖歧义。

### 8.5 数据建设的完整规模与来源

- **先交付 P0 诊断集：** 目标 **120 个独立基础故事家族**，每家族至少 2 个最小对照版本，目标总量不少于 **240 条**；覆盖工作办公、日常生活、协作/服务三个域，以及中断时长/负荷、可见性、目标冲突、任务恢复条件等分层因素。该数量是**研发目标**，不是已经完成的数据量。
- **分组划分：** 以基础故事家族划分训练/开发/测试约 60%/20%/20%，测试集包含模板外表达与未见场景；同族变体不跨集合。
- **再建设 P1 实际行为数据：** 优先核查有许可的公开连续第一人称视频或任务日志能否可靠重标“中断—恢复”；不足时再进行经适当伦理与隐私流程的受控参与者任务。初期以数十名参与者、数百个有证据的中断片段为**预算/采集目标**，实际规模由资源和标注质量决定。
- **至少两名独立标注者**标 `V/F/A` 及可观察步骤；`B/C/Q` 对缺乏足够证据的真实场景允许 UNKNOWN。记录一致性、分歧、仲裁及标注手册版本。

## 9. 实验、指标与消融（完整项目必须交付）

### 9.1 主实验

1. **E1 P0 受控一致性：** 在 P01–P08 及扩展对照对上，报告状态准确率、关键对照差异、未来泄漏、步骤正确率和错误类型。
2. **E2 P1 真实恢复预测：** 报告实际是否恢复、恢复位置和概率校准，并对被截断的行为窗口使用明确的删失处理。
3. **E3 复杂度与长度：** 随事件长度、中断层数、任务数和缺失证据增加，测准确度及时间/算力开销。
4. **E4 跨域/跨人物泛化：** 按人物和任务族划分；不可把同一人物或同模板变体随机打散导致泄漏。
5. **E5 与 MWM 集成：** 原始 MENTIS、等量记忆 MENTIS 与 ECR-MWM，在相同输入信息下比较；明确公开实现版本差异。

### 9.2 主指标

| 指标 | 对应任务 | 说明 |
|---|---|---|
| Macro-F1 / Balanced Accuracy | `C` 等已证实状态标签 | 类别不均衡时比单一准确率更稳定 |
| Resume F1、AUROC、AUPRC | T1 实际恢复 | 只用于有真实结果或明确 P0 脚本规则的数据，不能混作同一结论 |
| Brier Score、ECE | T1 恢复概率 | 评价校准，需足够真实样本及固定时间窗口 |
| Step Accuracy / Top-k Accuracy | T2 恢复步骤 | 对确实恢复、且可辨认恢复步骤的记录计算 |
| Invalid Resume / Knowledge Leakage Rate | 状态约束 | 已知取消却错误恢复、把不可见事件当人物已知等 |
| Pairwise Consistency | P0 成对诊断 | 分别统计应改变的对与应不变的负对照 |
| Cost：tokens/latency/GPU | 效率 | 排除单纯堆算力或输入长度的解释 |

结果同时报告 `n`、分层条件、置信区间、单样例输出与错误类别；不只给总分。

### 9.3 必须执行的算法消融

- A0 完整 ECR-MWM；
- A1 去除信息可达性门控（客观事件直接更新信念）；
- A2 去除承诺—进度联合更新（分别预测字段）；
- A3 去除持久目标记忆（只保留最近窗口）；
- A4 去除事件一致性损失；
- A5 去除恢复位置辅助任务；
- A6 用规则门控代替可学习门控；
- A7 只增加等量历史摘要/提示 tokens，不使用新机制。

所有对照报告输入与推理预算，并检查是否在**“客观相同、人物知晓不同”**与**“历史相同、后续不同”**两类样例上满足应有性质。
