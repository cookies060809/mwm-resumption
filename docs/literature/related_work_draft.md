## 1. 心智世界模型与心理状态推断

世界模型长期以物理状态为中心：预测“什么在哪里、将如何变化”。MWM/MENTIS [4] 指出，只跟踪物理场景而忽略每个 agent 的信念与知识，会在场景看似正确时预测错动作；它把状态扩展为物理组件与心智组件的耦合表示，并用第一人称观测函数区分“世界是什么”与“目标看到了什么”。MENTIS 以可校验的 JSON 表示状态，在 Menti-Bench 上用必要性阶梯（S0–S6）验证显式状态与转移模拟的作用：完整模型 F1 为 90.7，人类参照为 98.5（论文自报），oracle 干预显示转移模拟是最大单点瓶颈。MMEA [3] 进一步提出 Mental World Model 与分层心理演化架构，在 DynToM / RecToM 上报告 96.48% / 94.00% 准确率（论文自报）。

这一路线与本项目共享“行为预测需要心智状态”的前提，但预测对象不同：MWM/MMEA 让**agent 自身**维护并演化心理状态；本项目让**外部观察者**从不完整事件历史推断**人物**的状态，并输出“是否恢复、恢复到哪一步”。因此本项目不能宣称首次把心智状态引入世界模型，差异只能落在观察者视角、六因子联合状态与恢复步骤预测上。

## 2. 中断后的在线状态更新

EchoChain [1] 是首个专门评测“全双工语音助手在被打断后更新任务状态”的受控基准：200 段被打断对话、四个闭源实时语音模型，报告整段通过率与 rubric 通过率；四个模型的整段通过率均低于 50%（论文自报）。它把失败归为三类：Contextual Inertia（口头承认打断但不改内容）、Interruption Amnesia（忘记打断前的约束）、Objective Displacement（目标被替换）。

DuplexLedger [2] 把问题推进到持久记忆：会话被形式化为事件流，记忆项带 active/superseded 状态，事件级操作为 `WRITE / UPDATE / IGNORE / RETAIN`；1,094 个中英双语会话。五个系统没有一个同时占优；最好的 latest-value 准确率为 25.50%，但 final-state 覆盖仅 1.06%，而最好的 final-state 覆盖只有 2.01%（论文自报）。其 ACT-Mem 在 219 个留出会话上把 latest-value 准确率从 4.11% 提到 8.68%，代价是打断停止变慢。

二者的预测对象都是**agent 自己的状态或记忆**；本项目预测的是**人物**的隐藏状态，且标签来自事件证据而非 rubric 或构造的参考账本。我们因此不主张“首个中断后状态更新基准”。

## 3. 目标识别与信念跟踪

SIPS [8] 用 PDDL 表示状态与目标，对 boundedly-rational agent 建模，并用序贯蒙特卡洛在线近似目标后验；它能从次优甚至失败的动作序列中推断目标。其局限由作者明确给出：目标集有限、目标是最终的而非层级/工具性的、主要考虑确定性转移与有限动作空间。

Windowed Goal Recognition [7] 在现有识别器外挂滑窗，只把当前窗口内的状态—动作序列送入识别，以检测目标变化；在 Autonomous Squad Member、Rovers、Childsnack 三个域上优于不设窗口的 SET-PR（论文自报）。它的目标是离散、可枚举的，也没有“暂停/放弃/承诺”状态。

SymbolicToM [9] 从故事逐句构建多角色信念图，支持 k 阶嵌套信念，以解码时插件的方式增强 off-the-shelf LLM，无需训练；在 ToMi 等 false-belief 任务上优于 zero-shot 与 memory 基线。其局限是假设故事按时间顺序书写，且三元组抽取依赖外部模型。

这一路线提供了“目标后验”与“人物信念”的强参照，但都缺少承诺状态 `C`、主观进度 `Q` 与恢复步骤 `T2` 的联合建模。本项目不宣称首次做目标识别或信念跟踪。

## 4. 目标生命周期、暂停与恢复契约

BDI 2008 [6] 给出任务暂停与恢复的形式化机制：任务被暂停时附带重新考虑条件，条件为真时进入下一轮慎思，可选择恢复、继续暂停、终止或其他元动作；承诺强度由效用、优先级、截止期、成本、目标间依赖与交互、已投入努力、预计成功概率等因素决定。其实现（CAN 语言）采用自顶向下的暂停/恢复与选择性重新激活子目标。

GODR [5] 把目标生命周期、目标结构、恢复契约与失效关系显式化为运行时对象：目标结构是有向图，关系含 `parent / depends_on / blocks / supersedes / resumes / invalidates`；它明确与 BDI 兼容但更窄，只解决对话目标连续性，不要求完整 BDI agent。

二者都是**从 agent 内部管理目标**；本项目是**从外部证据推断**人物是否仍承诺、是否恢复。我们不宣称首次设计暂停/恢复生命周期或恢复契约。

### 2.1 邻近但不同的 agent 侧基准

NAQD Env [13] 评测语言 agent 在证据变化或权限撤销时的**选择性撤回**：暂停受影响动作、保留其余工作、修复后恢复；它是合成环境与确定性参考策略，测的是策略应用而非人物状态。ProAgentBench [14] 用 500+ 用户、28,000+ 事件的真实工作流评测主动辅助 agent 的介入时机与内容；它关注“何时帮忙”，不预测人物是否恢复原任务。BeliefTrack [15] 研究模型何时更新/保留信念，用闭环符号任务与验证器训练；它接近 `B` 维，但没有承诺、进度与恢复步骤。

三者都说明“状态/信念管理”本身已有专门基准；本项目的差异仍是**外部观察者 + 中断恢复步骤**，而不是再做一个 agent 侧状态管理基准。

## 5. 任务恢复的认知基础

目标激活与线索恢复的认知模型 [10] 用一般记忆的激活与联想启动解释目标管理，提出三个约束：旧目标残留造成的干扰水平、编码新目标的时间（强化）、线索在取回待办目标中的作用（启动），并用汉诺塔的暂停/恢复数据做仿真。这为“恢复位置与线索相关、恢复需要时间”提供了机制背景。

空间记忆实验 [11] 用注视模式发现人物中断后能回到非常接近中断前的位置，且空间性打断比非空间打断更损害恢复（摘要级）。恢复行为实验 [12] 发现中断带来恢复延迟与更高出错率，且当错误的时间代价高时，人物会更少出错但恢复更慢——恢复速度与准确性存在权衡（摘要级）。

[11][12] 为付费墙论文，本轮只到摘要级；因此这里只写方向性结论，不引用具体效应量。技术方案若需要激活公式，应直接引用 [10] 的 Appendix A 并按原文符号核对。
