## 1. 论文

| 项 | 已核实值 |

| 题名 | *Mental World Modeling* |

| 项目页 | `https://mental-world.github.io/`（摘要给出） |

摘要级主张（转述，未逐字核对）：

- 现有世界模型回答的是物理问题：什么/在哪/如何演化。
- 人类行为由隐藏心智状态驱动（信念、愿望、意图、感受、社会许可）。
- 只跟踪物理场景、不跟踪每个 agent 知道/相信什么，会在“场景看起来对”时预测错动作。

**不能占用：** “首次在世界模型加入目标/意图/心理状态”；“物理—心智联合状态”本身。

## 3. 与本项目的关系

| 维度 | MENTIS | ECR-MWM |
|---|---|---|
| 核心对象 | 一个 agent 的物理—心智世界状态 | 外部观察者对**人物**的六因子状态（V/F/A/B/C/Q） |
| 输入 | 部分观测 | 连续事件流 + 任务图 + 可获得的语义 |
| 关键约束 | 物理—心智耦合 | **认知可达性**（接触/理解门控）+ 承诺—进度联合 + 恢复步骤 |
| 任务 | 预测/规划 | T1 是否恢复、T2 恢复哪一步、T3 状态后验 |
| 数据 | 论文任务 | P0 受控脚本 + P1 公开数据派生 |

**安全表述：** “MENTIS 表明世界模型需要心智状态；ECR-MWM 关注的是外部观察者在信息不完整时如何约束该状态并预测恢复。”
**禁止表述：** “首次提出心智世界模型”“MENTIS 没有考虑人物状态”（摘要不足以支撑）。
