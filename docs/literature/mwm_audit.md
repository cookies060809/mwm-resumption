论文主张（转述自已读文本）：

- 现有世界模型回答的是物理问题：什么/在哪/如何演化。
- 人类行为由隐藏心智状态驱动（信念、愿望、意图、感受、社会许可）。
- 只跟踪物理场景、不跟踪每个 agent 知道/相信什么，会在“场景看起来对”时预测错动作。

**不能占用：** “首次在世界模型加入目标/意图/心理状态”；“物理—心智联合状态”本身。

### 2.1 论文中已核实的关键内容

- **状态定义**：物理组件（实体、属性、关系、环境条件）+ 心智组件（agent 级与场景级的信念、注意、目标、意图、情绪、偏好、关系、规范、氛围）。
- **观测**：目标观测 `o_t` 是对全局状态的第一人称渲染，不是原始像素副本；同一物理场景对不同 agent 可产生不同观测。
- **MENTIS 实现**：状态解析 → 观测生成（信息过滤）→ 动作分解（物理—心智接口）→ 耦合状态转移；状态以可校验 JSON 表示。
- **评测**：Menti-Bench 是小型“过程完整”测试台（文本叙事 / 1–5 张图像 + 场景锚 / 带声视频），标注覆盖联合状态、目标观测、动作与转移；8 个 LLM 世界模型；必要性阶梯 S0–S6。
- **结果（论文自报）**：完整 MWM 的 F1 为 90.7，人类参照 98.5；oracle 干预显示转移模拟是最大单点瓶颈（gold transition +3.5 F1），状态与观测次之。
- **与本项目最关键的差异**：Menti-Bench 是短故事/选择题式评测，不包含“中断后是否恢复、恢复到哪一步”的步骤级任务；其状态是 agent 自身的心智状态，不是外部观察者对人物的六因子推断。

## 3. 与本项目的关系

| 维度 | MENTIS | ECR-MWM |
|---|---|---|
| 核心对象 | 一个 agent 的物理—心智世界状态 | 外部观察者对**人物**的六因子状态（V/F/A/B/C/Q） |
| 输入 | 部分观测 | 连续事件流 + 任务图 + 可获得的语义 |
| 关键约束 | 物理—心智耦合 | **认知可达性**（接触/理解门控）+ 承诺—进度联合 + 恢复步骤 |
| 任务 | 预测/规划 | T1 是否恢复、T2 恢复哪一步、T3 状态后验 |
| 数据 | 论文任务 | P0 受控脚本 + P1 公开数据派生 |

**安全表述：** “MENTIS 表明世界模型需要心智状态；ECR-MWM 关注的是外部观察者在信息不完整时如何约束该状态并预测恢复。”
**禁止表述：** “首次提出心智世界模型”“MENTIS 没有考虑人物状态”（摘要不足以支撑）。
