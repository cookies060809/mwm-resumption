**用途**：测试信息泄漏、因果因素敏感性、目标状态一致性与成对逻辑；**不能**用于声称预测真实人类心理。

## 3. P1：真实行为数据

**用途**：在独立证据支持下评估真实恢复行为预测。

| 项目 | 计划 / 边界 |
|---|---|
| 来源 | 优先有许可的公开连续第一人称视频或任务日志；不足时再进行经伦理审批的受控参与者任务 |
| 初始规模 | 数十名参与者、数百个有证据的中断片段（预算/采集目标，非承诺） |
| 标注 | 至少两名独立标注者；`B/C/Q` 缺乏证据时允许 `UNKNOWN` |
| 标签 | 实际恢复行为、首次恢复步骤、删失状态 |
| 隐私 | 不提交原始视频/音频/屏幕记录/可识别日志；只提交批准的元数据或脱敏派生结果 |
| 当前状态 | 未采集；许可与伦理流程待确认 |

## 4. 标注与证据

- 事件字段、状态标签和硬性约束见 [标注手册](../annotation/annotation_handbook_v0.1.md)；质量门见 [质量方案](../annotation/label_quality_plan_v0.1.md)。
- 每条记录保存 `state_evidence_by_factor` 与平铺的 `state_evidence_event_ids`；P1 的未来观察证据不得进入预测输入。
- 双人标注一致性、分歧与仲裁记录必须可追溯；P1 的 `B/C/Q` 没有自述或可验证证据时保持未标注并遮蔽损失。
- P0 脚本标签与 P1 真实标签分表保存、分表报告；P0 的 `p0_expected` 不是真实行为标签。
- 当前 P0 数据：`data/p0/p0_samples.json`；A/B 逐字段审计：`python scripts/pair_diff_report.py`。

## 5. 已知限制

1. 首版仅结构化文本事件，不覆盖视觉识别、目标发现与机器人控制。
2. P0 是脚本化诊断数据，外部效度有限；当前只有 16 条种子，不能代表 120 家族的最终分布。
3. 领域覆盖不均衡：`daily_life` 当前仅有 P05 一对，扩增时优先补齐。
4. P1 的恢复行为归因可能存在歧义；无法辨认时记 `UNKNOWN`，不得强行标注。
5. 真实时间预测需要可靠时间戳与删失建模；合成文本中的“30 秒”不作为认知恢复时延真值。
6. 跨人物/跨任务泛化需要按人物与任务族划分；随机打散会造成泄漏。
7. Schema v0.1 中的任务依赖、客观进度、逐因子证据与结构化 P0 目标仍需 A 确认接口后才能批量扩增。
