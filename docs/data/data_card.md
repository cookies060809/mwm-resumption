## 2. P0：受控协议诊断集

**用途**：测试信息泄漏、因果因素敏感性、目标状态一致性与成对逻辑；**不能**用于声称预测真实人类心理。

| 项目 | 当前 / 计划 |
|---|---|
| 基础故事家族 | **120 个**（15 个任务骨架 × 8 个机制），已达目标 |
| 每个家族变体 | A/B 各 1 条最小对照 |
| 总量 | **240 条、1789 条事件** |
| 领域 | `work` 80 条、`collaboration_service` 84 条、`daily_life` 76 条（记录数） |
| 分层因素 | 8 个受控机制（接触/承诺/恢复位置/他人完成/资源/嵌套/未来泄漏/理解） |
| 划分 | 已完成：按 `base_story_id` 分层，train 72 / dev 24 / test 24（每机制 9/3/3），同族不跨集合 |
| 标签来源 | 明确脚本策略 + B 人工复核 |
| 标注状态 | `reviewed`；A/C 盲审（每机制 1 条）与仲裁待完成 |
| 校验 | `python scripts/validate_data.py`：240/240 通过；15 个 P07 家族输入一致性 PASS |

### P0 必含场景

P01 取消认知、P02 旧目标承诺、P03 恢复位置、P04 他人代完成、P05 暂时不可执行、P06 嵌套中断、P07 未来泄漏负对照、P08 接触但误解。定义见研究方案第 8.2 节；v0.2 中对应 8 个 `mechanism`，各 15 个家族。

## 3. P1：真实行为数据

**用途**：在独立证据支持下评估真实恢复行为预测。

| 项目 | 计划 / 边界 |
|---|---|
| 来源 | 优先有许可的公开连续第一人称视频或任务日志；不足时再进行经伦理审批的受控参与者任务 |
| 初始规模 | 数十名参与者、数百个有证据的中断片段（预算/采集目标，非承诺） |
| 标注 | 至少两名独立标注者；`B/C/Q` 缺乏证据时允许 `UNKNOWN` |
| 标签 | 实际恢复行为、首次恢复步骤、删失状态 |
| 隐私 | 不提交原始视频/音频/屏幕记录/可识别日志；只提交批准的元数据或脱敏派生结果 |
| 当前状态 | 未采集；许可与伦理流程待确认 |

## 4. 标注与证据

- 事件字段、状态标签和硬性约束见 [标注手册](../annotation/annotation_handbook_v1.0.md)；质量门见 [质量方案](../annotation/label_quality_plan_v0.1.md)。
- 每条记录保存 `state_evidence_by_factor` 与平铺的 `state_evidence_event_ids`；P1 的未来观察证据不得进入预测输入。
- 双人标注一致性、分歧与仲裁记录必须可追溯；P1 的 `B/C/Q` 没有自述或可验证证据时保持未标注并遮蔽损失。
- P0 脚本标签与 P1 真实标签分表保存、分表报告；P0 的 `p0_expected` 不是真实行为标签。
- 当前 P0 数据：`data/p0/p0_samples.json`；A/B 逐字段审计：`python scripts/pair_diff_report.py`。

## 5. 已知限制

1. 首版仅结构化文本事件，不覆盖视觉识别、目标发现与机器人控制。
2. P0 是脚本化诊断数据，外部效度有限；240 条来自 15 个任务骨架 × 8 个机制，同机制句式模板化，不能代表真实语言分布或自然行为分布。
3. 领域覆盖已接近均衡（work 80 / collaboration_service 84 / daily_life 76），但每个领域只有 5 个任务骨架，域内多样性仍有限。
4. P1 的恢复行为归因可能存在歧义；无法辨认时记 `UNKNOWN`，不得强行标注。
5. 真实时间预测需要可靠时间戳与删失建模；合成文本中的“30 秒”不作为认知恢复时延真值。
6. 跨人物/跨任务泛化需要按人物与任务族划分；随机打散会造成泄漏。
7. Schema v0.2 已扩到 240 条并固定 `split`；A 的适配器仍只认 `p0-record/v0.1.0`，需加版本分支后才能消费 v0.2；与 C 的 `person_access_evidence` 同名异型字段仍需映射。

## 6. 许可与伦理

- P0 种子批次仅用于内部研发与竞赛准备；正式开放前由团队确定许可证。
- P1 必须完成知情同意、隐私审查、数据最小化与访问控制；具体许可待定。
- 任何对外发布需移除可识别个人信息，并说明数据来源、采集时间、标注者与限制。
