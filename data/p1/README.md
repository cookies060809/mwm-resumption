# P1 真实行为数据

> **默认不入库。** 本目录只保留 README、公开数据派生包与经过批准的元数据规则。
> 原始视频、音频、屏幕录制、可识别日志、参与者信息与受限标注**禁止提交**。

> **竞赛阶段说明（2026-10-20，2026-10-23 补充）：** 真实人类 P1 仍未采集，不纳入当前竞赛提交。
> `public_derived/` 是从公开数据集已有标注重组出的**辅助任务候选集**，不是真人行为证据；
> 引用它时只能写"公开数据派生的候选集/流水线验证"，不得写成真实人类恢复预测能力。

  的已有标注重组出 2,863 条符合 P1 schema 的 JSONL，含转换脚本、校验器、数据卡与溯源清单。
  它是**三源辅助任务候选集**，主体分别是语音 agent、网页 agent 规格与双臂机器人 episode，
  **不满足正式 P1 的"真实人物跨中断恢复"定义**；规模、缺口与再分发限制见
  [`public_derived/README.md`](public_derived/README.md) 与 [`public_derived/docs/dataset_card.md`](public_derived/docs/dataset_card.md)。
- P1 schema 已有第一版（`public_derived/docs/schema.json`，与 P0 schema 完全分离）。它覆盖事件序列、
  六因子、删失与证据溯源，但**尚无真实采集需要的时间戳/观察窗口/逐标注者字段**（ISO 8601 时间、

## `public_derived/` 的入库边界

| 内容 | 是否入库 | 原因 |
|---|---|---|
| `scripts/`、`docs/`、`run_pipeline.sh`、`processed/*.jsonl` | 是 | 可复现的派生结果与规则，A/C 可直接读取 |
| `raw/*/[_manifest.json,_upstream_blobs.json,_upstream_tree_subset.json]` | 是 | 只含 URL / sha256 / 字节数，是溯源审计，不含上游内容 |
| `raw/` 里的上游标注正文 | 否（`.gitignore` 已挡） | 再分发权属于上游数据集；clone 后由 `run_pipeline.sh` 的 fetch 步骤就地取回 |
| 上游音视频、轨迹、视频包 | 否 | 体积与许可双重限制，本包从未下载 |

**InterruptBench 分片（1,815 条）许可证未确认** → 本仓库为私有仓库，仅供 A/B/C 内部评测；
对外发布、随竞赛材料分发或转公开前，必须先解决该分片的许可问题或将其剔除。

## 访问与存放

- 真实数据存放在团队批准的受限存储位置，访问权限按最小必要原则授予。
- 真实人类数据入库时仓库中只保留：数据字典、许可说明、脱敏后的聚合结果；
  `public_derived/` 这类**无个人信息**的公开数据派生内容按上表边界入库。
- 任何派生结果在入库前检查是否可反推个人身份或敏感场景。
- 数据许可、伦理审批与撤回机制由 B 维护，C 复核访问与泄漏风险。

## 标注要求

1. 至少两名独立标注者；先独立标注，再仲裁。
2. `V/F/A` 与可观察步骤基于独立证据；`B/C/Q` 仅在自述或可验证证据支持时标注，否则 `UNKNOWN`。
3. 记录是否恢复、恢复步骤、删失状态、观察窗口与证据事件 ID。
4. 恢复必须是可归属于原目标、推动尚未完成步骤的实际行为；仅谈论、返回地点或心里想做不算。
5. 未来观察证据不得进入 `observed_events`；截断点 `t` 之后的信息只用于评价标签。
6. 未覆盖完整窗口且未观察到恢复的样本记为 `right_censored`，不得直接记为 `not_resume`。

## 提交检查

- [ ] 不含原始媒体或可识别个人信息
- [ ] 许可与伦理审批已记录
- [ ] 未来信息未进入输入
- [ ] 删失状态已标注
- [ ] `B/C/Q` 的无证据标签为 `UNKNOWN`
- [ ] 派生结果不可反推个人身份
