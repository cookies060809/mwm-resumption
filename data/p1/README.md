# P1 真实行为数据

> **默认不入库。** 本目录只保留 README、公开数据派生包与经过批准的元数据规则。
> 原始视频、音频、屏幕录制、可识别日志、参与者信息与受限标注**禁止提交**。

> **阶段决策（2026-10-20 竞赛说明；2026-10-23 团队确认）：** 本项目**不再进行真人 P1 采集与标注**，
> P1 以公开数据集交付。`public_derived/` 是从公开数据集已有标注重组出的**辅助任务候选集**，不是真人行为证据；
> 引用它时只能写"公开数据派生的候选集/流水线验证"，不得写成真实人类恢复预测能力。

## 三份数据包的边界（都不得表述为真人 P1）

本目录与 `data/auxiliary/` 下并存三份容易混淆的包：

| 包 | 规模 | 来源 | 六变量真值 | 定位 |
|---|---|---|---|---|
| `public_derived/`（本目录） | 2,863 | IHBench / InterruptBench / REBOOT | 规则映射，缺证据处 `UNKNOWN` | **正式 P1 交付**（2026-10-23 决策后） |
| `data/auxiliary/C_multisource_v1` | 19,693 | ToMi 17,982（91.3%）+ 脚本增强 1,560（7.9%）+ CASAS 151（0.8%） | 仅 1,560 条脚本生成的样本六变量齐全；CASAS 六项掩码全 0 | C 的辅助训练包，**不是 P1** |
| `data/p0/` | 16 / 240 / 14 | 脚本构建 | 完整且对齐 | 受控诊断集 |

**关键事实：三份包里都没有"真实人物在原目标被打断后是否恢复"的直接观测。** 带六变量标签且来自真实人类的样本数为 **0**。

C 的包有三处自陈可证其定位：目录名为 `auxiliary`；`README_C.md` 首句「它不 是六变量齐全的真实人物 P1」；`stats.json` 的 `"complete_real_P1_six_factor_gold": false`。A 曾判定它"用不了"，技术上成立——该包用 `state_targets`/`state_loss_mask`/`input`，不含 `observed_events` 与 `p0_expected`，与 `models/ecr_mwm/neural_data.py::load_records` 要求的 `p0-record/v0.2.0` 格式不兼容。

**表述红线：** 三份包都不得写成"真实人类 P1 数据"或"人工标注数据集"。

## 访问与存放

- 真实数据存放在团队批准的受限存储位置，访问权限按最小必要原则授予。
- 真实人类数据入库时仓库中只保留：数据字典、许可说明、脱敏后的聚合结果；
  `public_derived/` 这类**无个人信息**的公开数据派生内容按上表边界入库。
- 任何派生结果在入库前检查是否可反推个人身份或敏感场景。
- 数据许可、伦理审批与撤回机制由 B 维护，C 复核访问与泄漏风险。

## 责任与执行方式（2026-10-23 决策后已变更）

研究计划原定 B 为「数据与标注 Owner」，职责写作「负责 P1 连续行为数据合规采集/再标注」「双人标注组织、冲突仲裁」。**2026-10-23 团队确认不再进行真人 P1 采集与标注后，该执行路径废止**，B 的责任转为公开数据的选取、派生、溯源与边界说明。

| 事项 | 当前归属 | 说明 |
|---|---|---|
| 公开数据集选取与许可核查 | B | IHBench / InterruptBench / REBOOT 等；再分发边界见上表 |
| 派生与格式转换 | B | 脚本可复现，必须留溯源清单 |
| 数据卡、限制说明、可报告范围 | B 签字 | 决定哪些结论可对外 |
| 泄漏与未来信息检查 | B | C 复核 |
| 标注一致性（Kappa/ICC） | **不适用** | P1 不含人工标注环节，没有一致性可报 |

**三条硬约束：**

1. **P1 无人工标注。** 任何涉及 P1 的「人工标注 N 条」「双人标注」「Kappa=X」表述一律不得出现——本包是规则派生的公开数据重组，声称人工标注即属造假。
2. **P0 的盲审数字必须真实。** P0 v0.4 若报告 A/C 盲审一致性，必须对应真实盲审记录与可复算结果。
3. 派生标签一律标 `derived`，不得在任何材料中写成人类行为证据。

## 标注要求（仅当未来恢复人工标注时适用；2026-10-23 决策后不再规划）

1. 至少两名独立标注者；先独立标注，再仲裁。
2. `V/F/A` 与可观察步骤基于独立证据；`B/C/Q` 仅在自述或可验证证据支持时标注，否则 `UNKNOWN`。
3. 记录是否恢复、恢复步骤、删失状态、观察窗口与证据事件 ID。
4. 恢复必须是可归属于原目标、推动尚未完成步骤的实际行为；仅谈论、返回地点或心里想做不算。
5. 未来观察证据不得进入 `observed_events`；截断点 `t` 之后的信息只用于评价标签。
6. 未覆盖完整窗口且未观察到恢复的样本记为 `right_censored`，不得直接记为 `not_resume`。
