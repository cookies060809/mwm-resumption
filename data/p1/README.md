## 标注要求

1. 至少两名独立标注者；先独立标注，再仲裁。
2. `V/F/A` 与可观察步骤基于独立证据；`B/C/Q` 仅在自述或可验证证据支持时标注，否则 `UNKNOWN`。
3. 记录是否恢复、恢复步骤、删失状态、观察窗口与证据事件 ID。
4. 恢复必须是可归属于原目标、推动尚未完成步骤的实际行为；仅谈论、返回地点或心里想做不算。
5. 未来观察证据不得进入 `observed_events`；截断点 `t` 之后的信息只用于评价标签。
6. 未覆盖完整窗口且未观察到恢复的样本记为 `right_censored`，不得直接记为 `not_resume`。
